# 저시드 예비런으로 계산한 설계 검정력은 낙관적이다 — 두 배 이상

> 시드 16개 예비런으로 "`k = 256` 이면 `4.19σ`" 를 계산하고 사전등록했다.
> 실제로 돌리니 **`1.61σ`** 였다. 예측이 **2.6배 낙관적**이었다.

## 무엇을 재려 했나

`soft-r3` 2D 계에서 초기배치→정상상태 결함 완화시간 `τ` 가 `A = 0.1` 과 `A = 1` 에서
다른가. 예비 관측(시드 16개): `diff = +0.01090 ± 0.01041 τ_d = 1.05σ` — 구별 안 됨.

`simbot.estimators.seeds_for_target_sigma` 로 `SE ∝ 1/√k` 를 써서 `3σ` 에 `k = 137`,
여유를 두어 `k = 256` 을 사전등록했다 (예상 `4.19σ`).

## 무엇이 나왔나 — 두 원인이 곱해졌다

| | 시드 16개 | **시드 254개** | 변화 |
|---|---|---|---|
| `τ(A=0.1)` | `0.03110` | `0.02975` | `−4.3 %` |
| `τ(A=1)` | `0.04200` | `0.03672` | `−12.6 %` |
| **`diff`** | `0.01090` | **`0.00696`** | **`−36.1 %`** |
| `SE_diff` (부트스트랩) | — | `0.00432` | |
| **`σ`** | `1.05` | **`1.61`** | 예상 `4.19` |

### 원인 ① 저시드에서 `τ` 가 위로 편향된다

`A = 1` 의 `τ` 가 시드 수와 함께 **단조 감소**했다:

```
k=4   τ = 0.0613
k=16  τ = 0.0420
k=254 τ = 0.0367
```

3파라미터 지수 적합(`y_inf + (y_0 − y_inf) e^{−t/τ}`)에서 **`τ` 와 진폭이 상관되어
있고, 잡음이 둘을 함께 키우는 방향으로 적합을 끈다.** 시드 평균 곡선의 잡음이
`1/√k` 로 줄면 그 편향도 줄어든다.

`A = 1` 이 가장 심한 이유: **완화 폭이 잡음의 4.1배뿐**이었다
(`A=0.1` 은 11.7배, `A=10` 은 10.6배). `k = 254` 에서는 13.5배로 올라갔다.
⇒ **폭/잡음이 작은 지점이 편향도 가장 크다.**

### 원인 ② `curve_fit` 공분산이 시드 앙상블 SE 를 과소추정한다

| | `SE_fit` | `SE_bootstrap` | 비 |
|---|---|---|---|
| `A = 0.1` | `0.00070` | `0.00100` | **`1.43`** |
| `A = 1` | `0.00271` | `0.00420` | **`1.55`** |

`fit_relaxation` 의 `tau_se` 는 **시드 평균 곡선 하나**에 대한 적합 불확실성이다.
이 저장소의 규약은 "시드 앙상블이 오차의 정직한 추정치" 이므로, 시드를 복원추출해
다시 적합한 분포의 산포가 옳은 오차다 (`bootstrap_relaxation_over_seeds`).

**같은 데이터로 `curve_fit` SE 를 쓰면 `2.48σ`, 부트스트랩을 쓰면 `1.61σ` 다.**
문턱이 `3σ` 이므로 판정은 안 갈리지만, `2σ` 문턱이었다면 갈렸다.

### 두 원인이 격차를 정량적으로 설명한다

```
4.19σ × (0.00696/0.01090) / 1.55 = 1.72σ  ≈  관측 1.61σ
        ↑ 편향된 diff          ↑ 과소추정된 SE
```

## 2단계 (`k = 1536`) — 또 빗나갔고, 이번엔 원인이 정확히 보인다

`k = 254` 의 신뢰할 수 있는 추정으로 `3σ` 에 `k = 886` 을 계산하고 `k = 1536` 을
사전등록했다 (예상 `3.96σ`). 결과 **`2.52σ` — 또 INCONCLUSIVE.**

같은 궤적의 **중첩 부분집합**으로 사다리를 만들자 이유가 드러났다:

| `k` | `τ(A=0.1)` | 폭/잡음 | `τ(A=1)` | 폭/잡음 | `diff` | `σ` |
|---|---|---|---|---|---|---|
| 4 | `0.03277` | `6.0×` | `0.06133` | **`2.3×`** | `+0.02856` | — |
| 16 | `0.03110` | `11.7×` | `0.04200` | `4.1×` | `+0.01090` | — |
| 64 | `0.03176` | `23.5×` | `0.03841` | `7.6×` | `+0.00665` | `0.60` |
| 256 | `0.02983` | `44.4×` | `0.03696` | `13.7×` | `+0.00713` | `1.52` |
| **512** | `0.03071` | `56.3×` | **`0.03468`** | **`20.2×`** | `+0.00396` | `1.30` |
| 1024 | `0.03050` | `85.5×` | `0.03480` | `27.7×` | `+0.00430` | `2.09` |
| 1513 | `0.03039` | `102×` | `0.03472` | `37.0×` | `+0.00433` | `2.52` |

### ★★ 편향은 시드 수가 아니라 **폭/잡음**이 정한다

- **`τ(A=0.1)` 은 처음부터 편향이 없다.** `k = 4` 에서 이미 폭/잡음이 `6.0×` 였고,
  `k = 4 → 1513` 동안 추세 없이 `0.0298–0.0338` 를 요동한다.
- **`τ(A=1)` 은 `−43 %` 내려가고 `k ≈ 512` 에서 평탄해진다.** 그 지점이 폭/잡음
  `20×` 다.
- ⇒ **규칙은 "시드를 늘려라" 가 아니라 "폭/잡음 `≳ 20` 을 확보하라" 다.**
  같은 `k` 에서 두 조건의 편향이 전혀 다르므로 시드 수는 대리변수일 뿐이다.
  폭/잡음 `< 10` 이면 `τ` 가 수십 % 위로 편향된다고 가정하라.

### ★ `diff` 는 0 으로 가지 않는다 — 평탄해진다

`k ≥ 512` 세 점의 평균 `+0.00420 ± 0.00020`. 차이는 `τ` 의 `12 %` 로 작지만
**있어 보이고, `3σ` 로 분해되지 않았다.** 수렴된 추정으로 `3σ` 에는 `k = 2145`
(현재의 `1.42` 배)가 필요하다 — 그러나 사전등록에 `no_stage_3: true` 를 박아
두었으므로 **돌리지 않았다.**

> 이 항목은 원래 초안에서 "`diff` 가 계속 줄어드니 0 으로 갈 수도 있다" 로 적혀
> 있었다. **사다리가 그것을 기각했다** — `k ≥ 512` 에서 평탄하다. 예비 관측의
> 단조 추세를 외삽하지 말 것.

## ★ 부수 발견 — 부트스트랩 SD 는 저시드에서 이상치가 지배한다

| `k` | `A=1` SD | 강건 SE (95 % 구간/3.92) | 비 |
|---|---|---|---|
| 4 | **`82.09`** | `0.4067` | `202` |
| 16 | **`36.10`** | `0.0206` | `1755` |
| 64 | `0.01084` | `0.00794` | `1.4` |
| 1513 | `0.00166` | `0.00160` | `1.0` |

`k = 4` 에서 SD 가 `82 τ_d` 다 — `τ` 자체가 `0.061` 인데. 재표집 몇 개가 적합
상한 근처의 `τ` 를 내면 SD 가 거기에 지배된다.
⇒ **적합 파라미터의 부트스트랩 오차는 SD 가 아니라 백분위 구간으로 보고한다.**
`bootstrap_relaxation_over_seeds` 가 `tau_ci95` 를 함께 돌려주는 이유다.

## 규칙

**① 설계 검정력의 입력이 저시드 예비값이면 그 검정력도 예비값이다.**
`k_needed = k_current · (목표σ/현재σ)²` 는 `diff` 와 `SE` 가 옳다고 가정한다.
`k_current` 가 작으면 **둘 다 틀릴 수 있고 같은 방향으로 틀린다.**

**② 폭/잡음(진폭÷잡음)이 편향의 지표다 — 시드 수가 아니다.** 실측 기준:

| 폭/잡음 | `τ` 편향 (최종값 대비) |
|---|---|
| `2.3×` | `+77 %` |
| `4.1×` | `+21 %` |
| `7.6×` | `+11 %` |
| `13.7×` | `+6.5 %` |
| **`≳ 20×`** | **`< 1 %`** |

`R²` 로는 안 보인다 — `A=1` 의 `R²` 는 `0.149`(k=16) → `0.924`(k=1513) 였는데,
낮은 `R²` 는 잡음이 크다는 뜻일 뿐 **편향의 크기를 말해주지 않는다.**

**③ 적합 파라미터의 오차는 부트스트랩으로 낸다.** `curve_fit` 공분산은 다른 것을
잰다. 두 값을 **함께 보고**해서 비가 1 에서 멀면 그 사실이 드러나게 한다.

**④ 순차 설계는 각 단계를 따로 사전등록한다.** 유의해질 때까지 시드를 늘리면
optional stopping 이고 `σ` 는 "많이 돌렸다"만 뜻한다. 2단계의 `k` 는 1단계의
**신뢰할 수 있는** 추정치에서 다시 계산하고, **몇 단계까지 갈지 미리 정한다.**

## 구현

- `simbot.estimators.seeds_for_target_sigma` — `t(ν)` 보정 포함 (`ν = k−1`, 자기일관 반복)
- `simbot.analysis.structure.bootstrap_relaxation_over_seeds` — 시드 복원추출 재적합
- `scripts/soft2d_relax_seeds.py` — `k` 를 코드가 아니라 **봉인된 예측 파일이 소유**하고,
  실행 전에 재계산해서 봉인값과 다르면 **멈춘다** (실제로 1-off 불일치를 잡았다)
