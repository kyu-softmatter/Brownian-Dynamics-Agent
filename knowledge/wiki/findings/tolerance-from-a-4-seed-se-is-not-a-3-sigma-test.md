# 시드 4개로 뽑은 `SE` 로 세운 허용오차는 `3σ` 검정이 아니다

> `3√2·SE_prior` 를 허용오차로 썼는데 새 런의 `SE` 가 **5.3배** 컸다.
> 실제 편차는 `1.1σ` 인데 판정은 **FAIL** 이 나왔다.

## 무엇이 일어났나

선행 런의 시드 4개 평균과 새 런의 시드 4개 평균을 비교하려고 허용오차를
`3√2 · SE_prior` 로 세웠다 (두 4-시드 평균 차이의 `3σ`). `A = 1` 의 `ψ₆` 에서:

| | 값 |
|---|---|
| 선행 `SE` | `0.00047` |
| 허용오차 = `3√2 × 0.00047` | `0.00201` |
| **새 `SE`** | **`0.00248`** ← **5.3배** |
| 실제 `SE_diff = √(SE₁²+SE₂²)` | `0.00252` |
| 편차 | `0.00285` |
| **허용오차 기준** | `1.42×` 초과 → **FAIL** |
| **실제 `σ` 거리** | **`1.13σ`** → 구별 안 됨 |

같은 편차가 한쪽 기준으로는 FAIL 이고 다른 쪽으로는 무의미하다.

## 원인 — `SE` 추정치 자체의 불확실성

시드 `k = 4` 는 자유도 `ν = 3` 이다. 표본 표준편차의 상대 불확실성:

```
SD(s)/σ ≈ 1/√(2ν) = 1/√6 = 41 %
```

**`SE` 를 41 % 오차로 알고 있는 상태에서 그 `SE` 의 3배를 문턱으로 쓰면 문턱 자체가
41 % 흔들린다.** 선행 런의 `A = 1` `SE` 는 낮은 쪽 뽑기였다:
두 분산 추정치의 비 `(0.00248/0.00047)² = 28` 은 `F(3,3)` 분포의 상위 `~1 %` 다 —
경계선이지만 일어날 수 있는 값이고, `A` 3개를 봤으니 더 그렇다.

`A = 0.1` 과 `A = 10` 은 두 `SE` 가 비슷해서 PASS 했다 (`−0.34σ`, `−0.31σ`).
**즉 이 실패는 재현되지 않는 종류다** — 그래서 더 위험하다.

## 규칙

### ① 정규 분위수 대신 `t` 분위수를 쓴다

`ν = 3` 에서 양측 `99.7 %` 는 `z = 3` 이 아니라 **`t = 5.84`** 다.

| `k` (시드) | `ν` | `t(ν, 99.7%)` | `z = 3` 대비 |
|---|---|---|---|
| 4 | 3 | `5.84` | **1.95×** |
| 6 | 5 | `4.03` | 1.34× |
| 8 | 7 | `3.50` | 1.17× |
| 16 | 15 | `3.15` | 1.05× |

`3√2·SE → 5.84√2·SE = 0.0039` 이면 편차 `0.00285` 는 **PASS** 였다.

### ② 두 `SE` 를 풀링한다 (둘 다 있을 때)

사전에는 새 `SE` 를 모르므로 `SE_prior` 만 쓸 수밖에 없다. 그러나 **S7 에서
실제 `SE_diff` 로 다시 재서 몇 `σ` 인지 함께 보고한다.**
`"허용오차를 넘었다"` 와 `"유의하게 다르다"` 는 다른 말이다.
구현: `scripts/soft2d_time_series.py::check_predictions` 가 두 값을 모두 적는다.

### ③ 오차막대가 값싼 곳에서는 시드를 늘린다

이 런의 과도구간 패스는 12런 `3.9 s` 였으므로 **시드 16개(48런)가 `13 s`** 였다.
`k = 16` 이면 `t` 보정이 `1.05×` 로 사라진다. **`k = 4` 는 정책의 기본값이고
정답이 아니다** — 런이 짧으면 늘려야 한다 (CLAUDE.md §"오차 막대는 공짜다").

## 이것은 `wide-tolerance` 의 거울상이다

[[wide-tolerance-hides-significant-deviation]] 는 **넓은 허용오차가 유의한 편차를
PASS 로 가린 사례**다. 이것은 **좁은 허용오차가 무의미한 편차를 FAIL 로 만든 사례**다.

두 실패의 공통 원인은 하나다: **허용오차를 통계량의 실제 분포에서 뽑지 않았다.**
`tests/conftest.py` 규칙 ① ("허용오차는 이론 통계오차에서 뽑는다") 은 지켰지만,
**그 통계오차 자체가 추정치라는 사실**을 넣지 않았다.
