# `dt` 게이트는 `dt/τ_D`가 아니라 스텝당 변위로 걸어야 한다

## 질문

`master_plan.md` §5의 S3 NONDIM 게이트는 **`Δt/τ_D ≤ 1e-4`** 다. 이 값이 맞는가?

## 답 — 틀렸다. 실제로 돌아가는 시뮬레이션을 기각한다.

실제로 돌아가고 논문까지 나온 BD 시뮬레이션 세 개를 같은 축으로 환산했다.

| 출처 | `dt/τ_D` | `√(2D·dt)/σ` | `ε/kT` | 퍼텐셜 |
|---|---|---|---|---|
| 선행 slit 프로젝트 (`brownian_slit_sim`) | `1.0e-3` | 0.045 σ | — | harmonic soft disk |
| Xu 2023 (dynamic interfaces) | `2.0e-5` | 0.0063 σ | 1 | WCA |
| Quah `graybox_abp_mpc` (코드) | `1.67e-4` | 0.018 σ | **500** | WCA (LJ 절단) |
| | **↑ 50배 폭** | **↑ 7배 폭** | | |

### 우리 게이트로 판정하면

| | `dt/τ_D ≤ 1e-4` | `√(2D·dt) ≤ 0.1σ` |
|---|---|---|
| 선행 slit 프로젝트 | ★ **기각** | 통과 |
| Xu 2023 | 통과 | 통과 |
| Quah 코드 | ★ **기각** | 통과 |

**3건 중 2건 기각.** 사용자 본인의 선행 프로젝트와 랩의 공개 코드를 모두 거부한다.

## 왜 `dt/τ_D`가 나쁜 기준인가

`τ_D = σ²/D`는 **입자가 자기 지름을 확산해 지나가는 시간**이다. 좋은 시간 단위지만,
**수치 안정성의 직접적 척도가 아니다.**

적분이 깨지는 실제 이유는 **한 스텝에 입자가 너무 많이 움직이는 것**이다. 그 양은

```
확산 변위   √(2 D Δt)
이류 변위   u₀ Δt              (능동계)
힘 변위     F_max Δt / ζ        (강한 척력에서)
```

이고, 이걸 `σ`로 재야 "겹침이 생기는가"를 판정할 수 있다. `dt/τ_D`는 확산 변위의
**제곱**에 비례하므로(`√(2D·dt)/σ = √(2·dt/τ_D)`), 같은 변위 폭이 `dt/τ_D`에서는
제곱만큼 벌어진다. 표의 50배 대 7배가 정확히 그 관계다 (`√50 ≈ 7`).

> **핵심:** 물리적으로 의미 있는 양은 변위다. `dt/τ_D`는 그 제곱이라 폭이 과장된다.

## 제안하는 게이트

```
S3 NONDIM 게이트 (사전):
    확산 변위   √(2 D Δt) / σ   ≤  0.03      ← 권장, 3건 모두 통과 (0.006–0.045 중 2건)
    이류 변위   u₀ Δt / σ        ≤  0.01      ← 능동·흐름 있을 때만
```

| 문턱 | 근거 |
|---|---|
| `0.03 σ` | 3건 실측 0.006 / 0.018 / 0.045 의 중앙 부근. 보수적으로 잡되 랩 관행을 기각하지 않음 |
| `0.1 σ` | 이미 S8 진단에 있는 **사후** 최대변위 기준 |

**S3(사전)과 S8(사후)이 같은 양을 봐야 일관된다.** 지금은 S3가 `dt/τ_D`, S8이 변위라
서로 다른 축으로 판정하고 있다.

> ⚠️ **`0.03σ`는 3개 표본에서 나온 잠정값이다.** 확정하려면 `dt` 스윕 실측이 필요하다 —
> `2024-quah-graybox-abp-mpc-repo.md`의 재현 계획 3단계.

## `dt/τ_D`를 버리자는 것은 아니다

`τ_D`는 여전히 **기준 시간 단위**로 옳다 (`D7`). 무차원 원장에도 `Δt/τ_D`를 계속 기록한다 —
다른 논문과 비교할 때 필요하다. **게이트로 쓰지 말자는 것뿐이다.**

## 곁가지 발견 — `ε/kT = 500`인 WCA가 안정적이다 (`D8`)

선행 프로젝트는 *"WCA의 `r⁻¹³` 코어는 오버댐프에서 위험하다"* 고 경고하며 bounded harmonic을
권했다 (`brownian_slit_sim/src/forces.py:117`). 그런데 Quah 코드는 **`ε/kT = 500`** 이라는
매우 강한 WCA를 쓰고도 돈다.

`dt/τ_D`는 선행 프로젝트가 6배 크지만, **스텝당 변위는 0.045σ 대 0.018σ로 2.5배 크다.**

> **`D8` 잠정 결론:** WCA의 위험성은 퍼텐셜 자체가 아니라 **스텝당 변위와의 결합** 문제다.
> 변위를 0.02σ 이하로 유지하면 강한 WCA도 안정적이다.
> **확정하려면 재현 실험이 필요하다.**

## 남은 불확실성

- **표본 3개다.** 통계가 아니라 정황이다
- 셋 다 **2D**다 (선행 slit, Xu 브러시는 준2D, Quah 2D). 3D에서 다를 수 있다
- 힘 변위 `F_max Δt/ζ` 항은 아직 아무도 측정하지 않았다 — 강한 척력에서 지배적일 수 있다
- Modica 3편(BD 직결)이 paywall이라 못 봤다. 표본을 늘릴 여지
