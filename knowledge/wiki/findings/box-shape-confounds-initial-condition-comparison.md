# 상자 모양이 초기조건 비교를 교란한다

## 증상

`A/r³` 2D 계에서 **육방 초기배치 vs 무작위 초기배치**를 비교하려고 `A = 0.1, 1`
각각 시드 4개로 돌렸다. 결과가 두 곳에서 이상했다.

### ① `S(k)` 6겹 변조가 50배 갈렸다

| `A` | 육방 시작 | 무작위 시작 |
|---|---|---|
| 0.1 | **`0.3246 ± 0.0600`** (시드별 `0.2327 / 0.4608 / 0.2151 / 0.3900`) | **`0.0062 ± 0.0008`** (`0.0040 / 0.0060 / 0.0075 / 0.0073`) |

`Γ = 0.56` 이면 깊은 액체다. 그런데 육방 시작이 6겹 구조를 유지하는 것처럼 보였고,
**시드 산포가 무작위 쪽보다 75배 컸다.**

⚠ 같은 런의 `ψ₆` 는 육방 `0.0471 ± 0.0011`, 무작위 `0.0486 ± 0.0018` 로 **일치했다.**
"배향 질서는 없는데 `S(k)` 6겹만 남았다"는 물리적으로 앞뒤가 안 맞는다.

### ② 에너지가 `12.8σ` 갈렸다

`A = 1`: 육방 `4.1092 ± 0.0027` vs 무작위 `4.1772 ± 0.0046` kT/입자.
차이 `0.068`, 결합 SE `0.0053` → **12.8σ.**
**평형에서는 두 초기조건이 같은 앙상블이므로 에너지가 같아야 한다.**

## 진단 경로

1. **평형화가 부족한가** — 첫 의심. `ψ₆` 표류(후반−전반)를 봤더니
   육방 `+0.0009 ± 0.0031`, 무작위 `+0.0020 ± 0.0030` — **둘 다 0 과 구별되지 않는다.**
   표류가 없는데 값이 갈리면 평형화 문제가 아니다.
2. **시드가 부족한가** — 아니다. 시드 4개의 SE 가 작고 차이가 12.8σ 다.
3. **★ 상자를 보자** — 여기서 나왔다:

```
육방 시작:   Lx=10.7457  Ly=9.3060  종횡비 1.1547  r_cut=4.4600
무작위 시작: Lx=10.0000  Ly=10.0000 종횡비 1.0000  r_cut=4.8000
```

**두 초기조건이 다른 상자에서 돌았다.**

## 근본 원인

`cause_class: analysis` (실험 설계). 러너가 상자 모양을 **초기조건에 묶어** 두었다:

- 육방 배치는 주기경계와 정합해야 하므로 `Lx = n_x a`, `Ly = n_y a√3` → 종횡비 `1.1547`
- 무작위 배치는 그럴 이유가 없어 정사각 `L = √N` → 종횡비 `1.0`

같은 밀도(`n* = 1`)라도 상자 모양이 다르면 **두 가지가 함께 바뀐다:**

| 바뀌는 것 | 왜 | 크기 |
|---|---|---|
| **`r_cut`** | `r_cut = 0.98·min(L)/2 − buffer` 로 파생된다 | `4.46` vs `4.80` — **7.6 %** |
| **허용 k-벡터** | `k = 2π(m/Lx, n/Ly)` | 육방정합 상자에서는 Bragg 벡터가 **k-격자에 정확히 놓인다** |

### ①의 원인 — `S(k)` 6겹 변조는 상자 모양에 의존한다

육방정합 상자에서는 원래 격자의 Bragg 벡터가 허용 k-격자 위에 정확히 있다.
그래서 **잔여 밀도 변조가 조금만 남아도 6겹 성분으로 크게 잡힌다.**
정사각 상자에서는 그 벡터들이 격자에서 벗어나 있어 같은 물리가 작게 보인다.

⇒ **`sixfold_modulation` 은 상자 모양이 같을 때만 비교할 수 있다.**

### ②의 원인 — `r_cut` 차이가 격자합을 바꾼다

절단된 에너지 합의 차이를 추정하면 (2D, `n* = 1`, `A = 1`):

```
ΔU/입자 ≈ (1/2)·2πn·∫_{4.46}^{4.80} (A/r³) r dr = πnA[1/4.46 − 1/4.80] = 0.050
```

측정된 차이 `0.068` 과 **같은 자릿수다.** 남는 `0.018` 은 상자 모양 자체의
격자합 차이와 통계로 설명될 여지가 있다.

⇒ **에너지 차이는 평형화 부족이 아니라 `r_cut` 차이다.** 처음 의심이 틀렸다.

## 처방

**상자 모양을 초기조건에서 분리한다.** `Soft2DRunConfig.box_shape` 신설:

```python
box_shape: str = "auto"      # auto | square | hex_commensurate
#  auto 는 init 에 따라 갈린다 → 초기조건을 비교할 때는 반드시 명시
```

- `init="random", box_shape="hex_commensurate"` 가 이제 가능하다 → **양쪽이 같은
  상자·같은 `r_cut`** 에서 돈다
- `init="hex", box_shape="square"` 는 **예외를 던진다** — 육방 배치는 정합 상자에서만
  완벽하고, 정사각에 넣으면 주기경계가 격자를 끊어 인공 결함이 생긴다
- `random_2d_snapshot` 이 직사각 상자를 받도록 확장 (`box_x`, `box_y`)

검증:

```
init=random  shape=hex_commensurate  Lx=10.7457 Ly=9.3060 종횡비=1.1547 r_cut=4.4600
init=hex     shape=auto              Lx=10.7457 Ly=9.3060 종횡비=1.1547 r_cut=4.4600
```

## 적용 범위 — 이 함정은 여기서 끝나지 않는다

**상자 모양이나 크기가 다른 두 런을 비교하는 모든 곳**에 적용된다:

- **`N` 수렴 검사** — `N` 을 바꾸면 `L` 이 바뀌고 `r_cut` 도 바뀐다.
  `r_cut` 을 **명시적으로 고정**해야 `N` 효과만 본다
- **`A` 스윕** — 같은 `init`·같은 상자면 안전하다 (이번 스윕의 `A` 의존성은 유효하다)
- **`colloidal-crystal-2d--oscillatory-microrheology` §A9** — "대각선 방향" 을 만들려고
  격자를 돌리려 하면 같은 부류의 함정에 빠진다. 상자를 격자에 맞춰 다시 만들어야 한다
  ([[test_s5_pair]] 의 회전 테스트가 이미 그것을 고정했다)
