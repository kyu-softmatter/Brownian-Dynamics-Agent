# `choi2020_interfacial_rdf` — 계면 콜로이드 단층막의 `g(r)`

원 논문이 `g(r)` 일치를 **"excellent agreement"** 라고만 적었다. 그건 게이트가 아니다
(원칙 7: 판정 기준은 숫자여야 한다). 그래서 Figure 4B 곡선을 판독해 **정량 허용오차**를 만들었다.

## 3. 검사 정의 — 두 층으로 나눈다

### `L3` 코드-코드 — 우리 MC/BD 가 원 논문 MC 를 재현하는가

같은 퍼텐셜·같은 배치·같은 `Ω` 분포로 돌려 `Ω_hetero` 곡선을 재현한다.
**우리 구현이 맞는지**를 보는 검사이지 물리 검증이 아니다.

| 관측량 | 기대값 | 허용오차 |
|---|---|---|
| 1차 피크 높이 | 3.88 | **±15%** |
| 1차 피크 위치 `r/d` | 8.0 | **±0.3** |
| 2차 피크 높이 | 1.76 | ±20% |
| 3차 피크 높이 | 1.56 | ±25% |
| 꼬리 평균 (25–29.5) | 0.88 | ±0.15 |

### `L4` 실험 대조 — 물리가 맞는가

`Ω_hetero` 조건이 실험 `g(r)` 을 재현하는가. 위 표에서 `exp` 열을 기대값으로 쓴다.

| 관측량 | 기대값 | 허용오차 |
|---|---|---|
| 1차 피크 높이 | 3.88 | **±15%** |
| 2차 피크 높이 | 1.94 | ±20% |
| 3차 피크 높이 | 1.40 | ±25% |
| 꼬리 평균 | 1.01 | ±0.15 |

### ★ 판별 검사 — 이게 이 벤치마크의 핵심

> **`Ω_hetero` 는 통과하고 `Ω_max`·`Ω_min` 은 실패해야 한다.**

1차 피크 높이 하나로 갈린다:

```
Ω_hetero  3.88  →  exp 대비  +0%   →  ±15% 게이트 통과
Ω_min     7.11  →           +83%  →  실패
Ω_max     9.10  →          +135%  →  실패
```

**불균질을 넣지 않으면 1차 피크가 2배 이상 솟는다.** 이 순서를 재현하지 못하면
우리 구현이 `Ω` 불균질을 제대로 반영하지 못하고 있다는 뜻이다.
단순 통과/실패보다 **세 조건의 순서**를 검사하는 편이 강하다.

## 4. 게이트로 쓰지 말 것 — 1차 최소

`Ω_hetero` 가 실험 대비 **−57%** 다. 원 논문이 "excellent agreement" 라고 한 것은
1차 피크와 전체 형상에 대한 것이지 **모든 지점이 맞는다는 뜻이 아니다.**

1차 최소는 `g(r) ≈ 0.1–0.35` 로 값 자체가 작아 상대오차가 쉽게 커진다.
**기록은 하되 통과 기준으로 쓰지 않는다.**

## 5. 재현 조건 — 원 논문 설정

[계-동역학 카드](../systems/interfacial-colloid--equilibrium-structure.md) §5 참조.

`N = 247` · 2D · 초기배치는 실험 스냅샷 · `Δ(r/d) = 0.05` · `10⁶` 사이클 ·
`U_ij/kT = Ω_iΩ_j(d/r)³` · `Ω_max = 804.33` · `Ω_min = 202.18` · 브라운 확산 무시.

> ⚠️ **절단 거리가 미확정이다.** 원 논문이 언급하지 않는다. 카드 §7 참조 —
> CPS 조건에서 `U = kT` 사거리가 `r/d ≈ 68.9` 인데 박스 `L/2 ≈ 65 d` 다.
> **재현 실패 시 1순위 용의자.** 절단 반경 민감도를 먼저 돌릴 것.
