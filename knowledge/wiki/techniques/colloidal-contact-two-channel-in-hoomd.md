# 콜로이드 접착 접촉을 HOOMD 로 세우는 법 — 두 채널

> **한 줄:** 콜로이드 접촉은 **쌍포텐셜 하나가 아니라 채널 둘**이다.
> 법선은 `bond`, **접선은 `angle`**. 접선을 빼면 사슬이 토크를 못 지탱한다.

축약 단위: `σ = 2a`(결합 길이) · `kT` · `τ_D = σ²/D₀`.
수치 전부 `scripts/contact_bond_params.py` 산출 (PMMA `2a = 1.47 μm`, 물 298.15 K).

```
kT/σ  = 0.0028 pN          ← 힘 단위
kT/σ² = 0.001905 pN/μm     ← 스프링 단위
τ_D   = 6472.8 ms
```

---

## 1. 왜 두 채널인가 — 물리

| 채널 | 실체 | `U_ij(r_ij)` 로 표현? |
|---|---|---|
| **법선** | DLVO. PMMA 표면전위 `≈ -40 mV` 의 이중층 반발을 `MgCl₂` `50–500 mM` 로 **차폐** → vdW 1차 최소로 비가역 응집 → **JKR 접착 접촉** (반경 `a_c ≈ 40–46 nm`) | ✅ |
| **접선** | 그 유한 접촉면의 **접촉역학.** `W_SL`(고-액 접착에너지)로 **접촉선이 핀** 되어 구름·회전에 저항한다 | ❌ **불가능** |

```
a_c = (3π a² W_SL / 2K)^{1/3},   K = 2E/3(1-ν²),   W_SL⁰ = γ_L(1 + cos θ₀)
κ₀  ∝ a_c⁴ ∝ W_SL^{4/3}
```

**결합 강성은 접착에너지가 정한다.** Langmuir 논문이 계면활성제로 `W_SL` 를 낮춰
`κ₀` 와 `M_c` 가 함께 내려가는 것을 보여 이를 확인했다.

### ★ 왜 어떤 쌍포텐셜로도 접선을 못 만드나
직선 사슬의 굽힘 모드는 **접선 복원력이 없으면 zero-energy mode** 다.
Hard sphere·DLVO·임의의 `U_ij(r_ij)` 는 전부 중심력이므로 결합각에 아무 힘을 주지 않는다
→ `κ₀ = 0`. 접촉면이라는 **내부 자유도**가 있어야 토크가 생긴다.
Hard sphere 는 접촉면이 점이므로 `a_c = 0 → κ₀ = 0` 이다.

## 2. HOOMD 매핑

```python
# 채널 1 — 법선 (접촉 유지)
bond = hoomd.md.bond.Harmonic()
bond.params["b"] = dict(k=k_bond_star, r0=1.0)          # r0 = σ

# 채널 2 — 접선 (접촉면 탄성)  ★ 이게 본체
angle = hoomd.md.angle.Harmonic()
angle.params["a"] = dict(k=k_theta_star, t0=np.pi)      # t0 = π (직선)

# EI = k_theta * b,  b = σ = 1   →   κ_point = 48 EI/L³ = 48 k_theta/L³
```

`angle.Harmonic` 은 `θ = π` 에서 정상이다 — `U ∝ (π-θ)²`, 힘도 유한
(실측: `π-θ = 2e-6` 에서 `U = 2e-8`, `max|F| = 8e-5`).
**완전히 곧은 배치는 힘이 정확히 0인 정류점**이다 (`eps = 0` 과 `1e-9` 에서 `F = 0.0`) —
이것이 `dt` 힘 게이트를 무력화하므로 §4를 반드시 읽을 것.

### 거리 구속은 쓰지 않는다
`md.constrain.Distance` 는 `Brownian` 과 호환되지 않고 **조용히 발산한다**
(결합 길이 `1.0 → 5.8×10⁷`, 그런데 `check_finite` 통과).
[[dead-end-distance-constraint-with-brownian]]

## 3. 문헌값 → 파라미터

`κ₀ = 24 EI/a³` (계수는 poppler 렌더링으로 확정 — [[2005-pantina-furst-bending-coefficient]]),
`EI = k_θ σ` 에서 **`k_θ = κ₀ a³ / (24 σ)`**.

| `[MgCl₂]` | `κ₀` | `EI` | `k_θ` | **`k_θ*`** |
|---|---|---|---|---|
| 10 mM | `64 ± 0.5 mN/m` | `1.059e-21 N·m²` | `7.203e-16 J` | **`1.750e5`** |
| 250 mM | `≈0.21 N/m` | `3.474e-21` | `2.364e-15` | `5.742e5` |
| 500 mM | `≈0.64 N/m` | `1.059e-20` | `7.203e-15` | `1.750e6` |

### 법선은 물리값을 쓸 수 없다 — 그리고 그래도 된다
JKR/Hertz 접촉 법선 강성 `k_n ≈ 2E*a_c`, `E* = E/2(1-ν²) = 1.845 GPa`:

```
k_n  = 147.6 N/m = 1.48e8 pN/μm      k_n* = 7.75e10
안정성 게이트 →  Δt* ≤ 1.29e-12 τ_D      ← 완전히 비현실적
```

**그런데 접선이 법선보다 `10⁵~10⁶` 배 부드럽다** (`k_θ*/k_n* = 2.3e-6 … 2.3e-5`).
즉 **법선을 `10⁴` 배 물러뜨려도 굽힘 측정은 안전하다.**
⇒ 규약: **`k_bond* = C · κ(N)*`, `C ~ 100`.** 상수로 두면 스텝 수가 `L³` 로 늘어난다.
`C` 의 적정값은 `converge` 로 흔들어 정한다 (아직 미수행).

## 4. ★ `dt` — 안정성 게이트가 없으면 터진다

곧은 사슬은 `max|F*| = 0` 이라 **힘 변위 게이트가 무력화**된다. `kT = 0` 에서도 터진다.

```
Δt* = min( 확산 4.5e-4,
           힘   0.005/max|F*|,                        ← 곧은 사슬에서 무력
           안정 0.2 × 2/(4 k_bond* + 16 k_θ*) )        ← 거의 항상 binding
```
전문·실측 교정: [[dt-gate-needs-a-stability-term-for-stiff-bonds]]
엔진 구현: `simbot.nondim.choose_dt` (`dominant == "stiff_stability"`)

**결합 계에는 `guards.check_bond_lengths` 를 반드시 켤 것** — `check_finite` 로는
폭발을 못 잡는다 (`1.4e7` 도 유한하다).

## 5. 바로 쓸 수 있는 런 설정 (10 mM, `k_θ*` 를 문헌값으로 고정)

`k_theta_star = 1.7498e5`

| `N` | `L*` | `κ_sim*` | `κ_sim [pN/μm]` | `rms y_c [σ]` | `k_bond*` (C=100) | `Δt*` |
|---|---|---|---|---|---|---|
| 7 | 6 | `3.889e4` | `74.07` | `0.00507` | `3.889e6` | `2.18e-8` |
| 11 | 10 | `8399` | `16.00` | `0.01091` | `8.399e5` | `6.49e-8` |
| 15 | 14 | `3061` | `5.831` | `0.01807` | `3.061e5` | `9.94e-8` |
| 21 | 20 | `1050` | `2.000` | `0.03086` | `1.050e5` | `1.24e-7` |
| 31 | 30 | `311.1` | `0.5926` | `0.05670` | `3.111e4` | `1.37e-7` |
| 41 | 40 | `131.2` | `0.2500` | `0.08729` | `1.312e4` | `1.40e-7` |

> **지수만 검증할 거면 `k_θ*` 를 문헌값으로 고정하지 말 것.** `κ ∝ L^{-3}` 은 `k_θ` 에
> 무관하므로, 열적 처짐이 잘 보이는 `k_θ* ~ 1e4` 에서 재는 게 싸고 정확하다
> (C1·C2 를 그렇게 했다: `p = -2.998 ± 0.003`, 계수 `0.991`).
> 문헌 `k_θ*` 는 **`G'(ω)` 를 물리 단위로 낼 때** 쓴다.

완화시간은 `τ_κ = γ/κ` 가 **아니다**: `τ_relax = 0.478 L τ_κ ∝ L⁴`
(기본모드 `τ₁ = γL⁴/π⁴EI`, 실측 3 % 일치). 런 길이를 `τ_κ` 로 잡으면 긴 사슬에서
이완이 안 끝난다 — `N=41` 에서 `κ` 가 22 % 높게 나왔다.

## 6. 아직 안 되어 있는 것 — 다음에 만들 것

| # | 무엇 | 어떻게 |
|---|---|---|
| **1** | **`M_c` 항복.** `angle.Harmonic` 은 항복하지 않는다 | `angle.Table` 로 `ε > ε_c` 에서 토크를 꺾는다. `M_c = 3.5e-17 N·m = 8503 kT`, **`ε_c = M_c/k_θ`: 10 mM 에서 `0.0486 rad = 2.78°`** (250 mM `0.85°`, 500 mM `0.28°`). 슬립 길이 `32 nm = 0.0218 σ ≈ a_c` |
| 2 | 결합 **생성·파괴** (겔화, 재배열) | `md.pair.aniso.Patchy*` — 토크를 주면서 토폴로지가 고정이 아니다. `angle` 매핑은 못 쓰고 `κ₀` 보정이 따로 필요 |
| 3 | 법선을 **물리적으로** (JKR 접착 우물) | `bond.Table` 또는 `pair.Table` 로 JKR 힘-변위 곡선. 다만 `k_n*` 이 `7.75e10` 이라 명시적 적분으로는 접근 불가 — 왜 필요한지 먼저 정할 것 |
| 4 | `d_b = 1.1` (DLCA 프랙탈) | `κ = κ₀(a/s)^{3.1}` — 우리는 직선 사슬(`d_b=1`)만 검증했다 |
| 5 | 비등방 항력 | 사슬은 `γ∥ ≠ γ⊥` 인데 `Brownian` 의 `default_gamma` 는 타입당 스칼라다. 현재는 등방 근사 |
