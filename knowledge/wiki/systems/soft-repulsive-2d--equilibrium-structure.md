## 3. 기준 단위 ★

| 차원 | 선택 | 왜 |
|---|---|---|
| 길이 | **`d = n^{-1/2}`** | ★ Zahn 규약. 최근접거리가 **아니다** (§아래) |
| 에너지 | `kT` | `A = βU(d)` 가 정의상 이 단위 |

### ★★ `d = n^{-1/2}` 이지 최근접거리가 아니다

Zahn 1999 의 `Γ = (μ₀/4π)M² π^{3/2}/(kT d³)` 에서 `d³ = n^{-3/2}` 이므로
**`d ≡ n^{-1/2}`** (면적 수밀도의 역제곱근)다.

육방격자의 최근접거리는 `a = (2/√3)^{1/2} d = 1.074570 d` — **7 % 다르다.**
`Γ ∝ d^{-3}` 이므로 이 7 % 를 혼동하면 **`Γ` 가 23 % 틀린다.**
상경계가 `Γ = 55.87 / 59.88` 로 4 % 간격이므로 23 % 오차는 **상을 오판한다.**

구현: `simbot.build.HEX_NN_OVER_D = 1.074570`, `simbot.analysis.structure.ZAHN_GAMMA_OVER_A = π^{3/2}`

**이 규약 하에 `n* = 1` 이 정의상 성립한다** → 정사각 상자 `L* = √N`.
육방격자 빌더가 `density_star = 1.000000` 을 내는 것으로 검산했다.

## 9. ★ 이 계의 난점 — `r_cut` 과 최소이미지가 충돌한다

`A/r³` 은 장거리다. `simbot.cutoff` 로 계산한 요구 `r_cut`:

| `A` | `r_cut/d` (structure 허용치) | 필요 `N` (`= 4 r_cut²`) | `N=100` 에서 `βU(r_cut)` |
|---|---|---|---|
| 0.1 | 2.15 | 19 | 0.0008 ✅ |
| 1 | 4.64 | 87 | 0.008 ✅ |
| **10** | 10.0 | **252** ❌ | **0.080** |
| **100** | 21.5 | **1857** ❌ | **0.800** |

`N_min ∝ A^{2/3}`. **그림의 `N = 100` 은 `A ≥ 10` 을 지탱하지 못한다.**

### 어느 기준으로 판단해야 하는가 — 미결

`simbot.cutoff` 의 허용치는 **`kT` 기준**(`βU ≤ 0.01`)이다. 그것은 `kT` 가 지배 척도일 때
옳다. 그런데 `Γ = 557` 결정에서는 **`A·kT` 가 지배 척도**다:

```
A=100, r_cut=4.8d:  βU(r_cut) = 0.90        (kT 기준으로 크다)
                    βU(r_cut)/A = 0.0090    (상호작용 기준으로 작다)
```

값). 절단오차가 `0.182 kT` 로 커지지만 **전 `N` 동일**이므로 거짓 기울기를 만들 수 없다.

**시드도 짝지었다.** `min_sep = 0.8 d` 기각표집 성공률이 시드마다 다르다
(실측, 시드 31–90: `N=64` `98.3 %` · `N=144` `95.0 %` · `N=256/400` `100 %`).
시드가 `N` 마다 다르면 `ψ₆(N)` 비교에 다른 초기배치 앙상블이 섞인다.

### 결과

| `A` | `p` | `η₆` | `χ²/dof` | 형태 판독 |
|---|---|---|---|---|
| 0.1 | `0.508 ± 0.020` | `2.03 ± 0.08` | `0.55` | ✅ 멱함수와 모순 없음 |

- **액체 대조군이 교과서대로 나왔다** — `p(A=0.1) = 0.508 ± 0.020`. `0.5` 에서 `0.4σ`.

- **방법이 견고하다.** `p(A=10)` 이 `0.316 ± 0.037` 로 §8.5 의 `0.366 ± 0.086` 과

  `80 τ_d`) · 시드가 **모두 다르다.** 세 축을 동시에 흔들었는데 같은 답이 나왔다.
- `N=256` 의 `ψ₆` 가 §8.5(자연 `r_cut = 7.74`)와 세 `A` 전부 일치 ⇒ **S16 이 절단오차
  `8.4배` 여행에서도 성립한다.**
- 결함 분율은 사다리 전체에서 평탄하다 (그림 ②).

### ⚠ `A=1` 의 `χ² = 4.07` — 휘어서가 아니라 **오차막대가 좁아서**다

잔차/σ = `+1.57  −2.14  +1.00  +0.24` → **부호 전환 2/3.**
멱함수가 틀렸다면(휘었다면) 부호가 단조 패턴을 만들어야 한다. 흩어져 있다.

`A=1` 의 상대 SE 가 사다리에서 가장 작다: `2.1 % · 1.3 % · 1.3 % · 1.4 %`.
**`χ² ∝ 1/SE²` 이므로 SE 과소추정이 4배로 증폭된다.**
`SE` 를 `2.02배` 로 늘리면 `χ²/dof = 1` 이 되는데, **4시드 SE 의 자체 불확실성이
`41 %`** 이므로 `2배` 과소추정은 충분히 일어난다
([[tolerance-from-a-4-seed-se-is-not-a-3-sigma-test]]).

⇒ **`χ²` 형태 검정은 4시드에서 SE-제한적이다.** 사전등록한 `χ² < 3` 문턱은
이 시드 수로는 신뢰성 있게 달성 가능한 검정이 아니었다 — **설계 실수**다.
`N=64` 를 빼도 `A=1` 은 `χ² = 2.00` 으로 통과하지만 `p` 가 `0.464 → 0.430` 으로
움직이므로 그 점을 버리는 것으로 해결되지 않는다.

> **`A=1` 의 형태는 미결로 남긴다.** `p ≈ 0.46` 이 액체(`0.5`)와 `2.8σ` 이내이고
> `η₆ = 1.86` 이 hexatic 상한의 `7.4배` 이므로 **상 판독은 흔들리지 않는다.**
> 흔들리는 것은 "멱함수인가" 라는 형태 주장뿐이다.
