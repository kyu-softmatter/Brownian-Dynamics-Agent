## 3. 기준 단위 ★

| 차원 | 선택 | 왜 이것인가 |
|---|---|---|
| 길이 | **격자상수 `d`** | 결함·구조·응력이 사는 척도다. `σ` 는 프로브 크기일 뿐이고 이 계에서 배제부피는 (희박 결정이면) 주역이 아니다 |
| 에너지 | `kT` | 열요동이 결함 생성의 경쟁자다 |
| 시간 | **`τ_d = d²/D₀`** | 격자상수만큼 확산하는 시간 |

### ★ 왜 이류 시간 `d/v` 를 기준으로 쓰지 않는가

`d/v` 가 이 계의 자연 시간처럼 보이지만 **`v` 는 스윕 대상**이다. 이류 시간을 기준으로
잡으면 `v` 를 바꿀 때마다 무차원 척도가 함께 변해서 스윕 결과를 나란히 놓을 수 없다.
`τ_d` 는 `v` 와 무관하므로 고정되고, **구동은 `Pe = vd/D₀` 하나로 들어온다.**

### ★ 왜 `τ_trap` 을 기준으로 쓰지 않는가

`τ_trap = γ/k = 8.06 ms` 는 이 계에서 **가장 빠른 시간**이고 `τ_d` 보다 훨씬 짧다.
기준 시간은 관측량이 사는 척도여야 하고, 우리가 보는 것(결함·응력 완화)은 격자 척도다.
`τ_trap` 은 **`Δt` 게이트를 지배하는 시간**으로 §7 에서 따로 쓴다 —
기준 시간과 게이트 시간은 다른 역할이다.

## 4. 무차원수 원장 ★

`d/σ` 가 정해지지 않았으므로 아래는 **`d = 3σ`(Zahn 계 전형) 가정**의 자릿수다.
확정 전에는 근거로 쓰지 말 것.

| 기호 | 정의 | 의미 | `v=0.5 μm/s`, `d=3σ` 에서 |
|---|---|---|---|
| **`Pe_d`** | `v d / D₀` | 구동 vs 확산 | **`292`** — 강하게 구동 |
| `Pe_σ` | `v σ / D₀` | 프로브 척도 구동 | `97.4` (측정된 값) |
| `Γ` | 쌍 상호작용 세기 (§10-A1 에 의존) | 결정성 | 육방 결정에 **`Γ > 59.88`** 필요 |
| `k* = k_t d²/kT` | 트랩 강성 | 프로브가 트랩을 얼마나 따라가나 | `d=30 μm` 면 `2.2×10⁶` — 극도로 강함 |
| **`τ_trap/τ_d`** | `γ/k ÷ d²/D₀` | 프로브 완화가 격자 시간보다 빠른가 | `4.6×10⁻⁷` — **6 자릿수 분리** |
| `ℓ_trap/d` | 열변위 / 격자상수 | 프로브가 트랩 안에서 얼마나 흔들리나 | `6.8×10⁻⁴` |

★ **`τ_trap/τ_d ~ 10⁻⁷` 이 이 계의 핵심 난점이다.** 트랩 완화는 ms, 격자 동역학은
수백 s — `Δt` 는 전자가 정하고 런 길이는 후자가 정한다. 그래서 스텝 수가 크다 (§8).

## 6. 관측량

| 양 | 어떻게 | 상태 |
|---|---|---|
| **프로브 힘** `F(t) = k_t (r_trap − r_probe)` | 트랩 변위에서 직접. **비리얼 불필요** | ✅ 안전 |
| **일 / 에너지** `W = ∫F·v dt` | 위의 시간적분 | ✅ 안전 |
| 결함 분율, 배위수 | Voronoi + `ψ₆ᵢ` (`freud`) | ⛔ `analysis/structure.py` 없음 |
| 전위(dislocation) = 5–7 쌍 | Voronoi 배위수 결함쌍 식별 | ⛔ 미구현 |
| **응력 텐서 · 스트레스 완화** | 비리얼 | ⛔ **차단** — 아래 참조 |
| `g(r)`, `S(q)`, `ψ₆` | `freud` | ⛔ `analysis/structure.py` 없음 |

### ⛔ 응력 텐서는 지금 쓸 수 없다

[[external-field-virial-convention]] 이 열려 있고, 그 문서가 **이 상황을 정확히 예고했다:**

> | 트랩 + 쌍 상호작용 (농후계) | ⚠️ **주의.** 쌍 비리얼과 섞이면 오염된다 |

사용자 목적의 "스트레스 릴렉스 과정 추적"이 여기 걸린다.

**우회로가 있다:** 프로브 힘 `F(t)` 의 시계열이 응력 완화의 대리 관측량이다 —
구동을 멈춘 뒤 `F(t)` 의 감쇠가 완화 과정을 보여준다. **비리얼을 쓰지 않으므로 안전하다.**
계 전체의 응력 텐서가 필요해지면 그 질문을 먼저 닫아야 한다.

## 9. ★ 사전 경고 — 힘 측정의 신호대잡음

`simbot.estimators` 로 계산한 값 (`v = 0.5 μm/s`, 그림의 `k_t`·`R`):

```
자유 항력      F = γv        = 0.0403 pN
그때 트랩 변위  F/k           = 4.03 nm      (열변위 l_trap = 20.35 nm)
힘 요동        k·l_trap      = 0.2035 pN
★ 표본당 SNR   F/F_noise     = 0.198        ← 1 보다 작다
10 % 정밀도에 필요한 독립표본  = 2548 개  (= 41 s 물리시간)
```

**한 번의 짧은 런에서 읽은 항력은 의미가 없다.** 다만 격자 10칸을 통과하려면
`200 s` 가 필요하고 (`d = σ` 가정) 그 안에 독립표본이 `~12000` 개 모이므로
**정밀도 `~4.5 %` 는 달성 가능하다** — 런이 다른 이유로 길어야 해서 우연히 해결된다.

★ **SNR 이 `v` 에 비례한다** → 저속 구간이 가장 어렵다. "선형 응답이니 쉽다"는
직관과 반대다. `v` 스윕을 설계할 때 저속 점에 표본을 더 줘야 한다.

## 10. 남은 빈칸 — **돌리기 전에 닫아야 하는 것**

### A1 ★ 쌍 상호작용이 그림에 없다 — **최우선**

"start from hexagonal equilibrium" 이라고만 적혀 있고 `U_ij` 가 없다.
육방 결정이 존재하려면 반발 상호작용이 필요하다.

**가설 (medium 신뢰도):** 동시에 들어온
[`soft-r3-2d-A-sweep`](../../../inputs/soft-r3-2d-A-sweep/sketch_01.jpeg) 의
**`U_ij/kT = A/r³`** 이 이 계의 상호작용이다. 근거:

1. 같은 날 같은 묶음으로 들어왔다
2. `A/r³` 은 상자성 콜로이드의 쌍극자 반발이고 **2D 육방 결정을 만드는 표준계**다
3. [[1999-zahn-two-stage-melting-2d]] 가 이 계의 상도를 갖고 있다:
   `Γ = 5.5683·A`, 결정 `Γ > 59.88` ⇒ **`A > 10.75`**

⇒ **`A = 100` (`Γ = 557`, 결정 영역 깊이 9.3배) 이면 안전하다.**
⇒ **`A = 10` 은 결정이 아니다** (`Γ = 55.68` < 59.88, 액체/hexatic 경계).

**확인이 필요하다.** 다른 후보: WCA 고밀도(`φ_A ≳ 0.7`), DLVO/Yukawa, 하드디스크.
어느 것이든 `Γ` 또는 등가 무차원수가 결정 영역에 있어야 한다.

### A2 면적밀도 / 격자상수 `d`

`N ≈ 300` 만 있고 상자 크기가 없다. `d/σ` 가 정해지지 않는다.
- Zahn 실험은 `a = 13.8–25.4 μm`, 입자 `σ = 4.5 μm` → **`d/σ ≈ 3–5.6` (희박 결정)**
- 근접 packing 이면 `d/σ ≈ 1`

`d/σ` 가 바뀌면 `Pe_d`·`r_cut`·런 길이·비용이 전부 바뀐다. §4 의 숫자는 `d = 3σ` 가정이다.

### A3 결함·응력 분석 코드가 없다
`analysis/structure.py` (Voronoi·`ψ₆`·전위) 와 응력 경로. §6 참조.

### A4 `HarmonicTrap` 의 중심이 고정이다
`r_trap(t) = r_trap(0) + vt` 를 넣으려면 `simbot/forces.py` 에 시간의존 중심이 필요하다.
`md.force.Custom` 은 `set_forces(timestep)` 를 받으므로 구현 가능하다.

### A5 `A/r³` 이 HOOMD 내장 포텐셜이 아니다
`md.pair.Mie(n=3, m=0)` 인지 `pair.Table` 인지 확인 필요.
`simbot/cutoff.py` 에도 거듭제곱 반발용 `r_cut` 제안이 없다 (`cutoff_from_tolerance` 가
일반적이지만 검증 안 됨).

### A6 자매 카드
같은 계를 **진동 구동**하는 [[colloidal-crystal-2d--oscillatory-microrheology]] 가 있다.
기준 단위는 같고 **게이트·관측량·무차원수가 다르다.**
