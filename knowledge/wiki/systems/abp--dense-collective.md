# `ABP` × `조밀 집단 거동`

**묻는 질문:** 자기추진 입자를 조밀하게 넣으면 무슨 일이 생기는가 — MIPS, 유리화, 집단 스웜.

> ⚠️ 이 카드의 기준 단위는 **다른 카드와 다르다.** 능동계에서는 회전이 주인공이라
> 기준 시간이 `τ_r`이고 `kT`가 유도량이 된다. [[passive-sphere--equilibrium-structure]]와 비교할 것.

---

## 1. 계

| 항목 | 값 |
|---|---|
| 입자 | 자기추진 구/디스크 (ABP). 힘 `f_p = ζ_t U₀`, 방향 `q(θ)` |
| 차원 | **2D**가 표준 (확인된 3편 모두) |
| 상호작용 | **WCA** — `md.pair.LJ` + `σ_LJ = d/2^{1/6}` + `r_cut = d` |
| 다분산 | **조밀계에서는 이분산 필수** — 지름비 **1.4**, 몰분율 **2/3 : 1/3** (Takatori 2020) |
| 경계 | 주기 (또는 채널 벽) |
| 용매 | 암묵적, HI 없음 |

## 2. 목적 동역학

| | |
|---|---|

## 3. 기준 단위 ★ — 능동물질 고유

| 차원 | 선택 | 왜 |
|---|---|---|
| 길이 | **런 길이 `ℓ = U₀τ_r`** (Quah) 또는 입자 지름 `σ` (Takatori) | 능동 입자의 자연 길이는 한 번 방향 유지하며 가는 거리 |
| 시간 | **`τ_r = 1/D_r`** (회전 재배향 시간) | 병진이 아니라 **회전이 동역학을 지배**한다 |
| 에너지 | `kT` — 단, **유도량일 수 있다** | Quah: `kT = D_r·ζ_r` (회전 Stokes–Einstein–Debye) |

**Quah 코드의 유도 사슬** (`hd_simulator.py:300-313`)

```
ℓ = 1,  D_r = 1,  ζ_t = 1                     ← 기준 3개
δ  = ℓ/√(ld2)                                  ← 미시 확산길이
a  = √(3/4)·δ                                  ← 입자 반지름
η  = ζ_t/(6πa)                                 ← Stokes 항력에서 점도 역산
ζ_r = 8πηa³                                    ← Stokes 회전 항력
kT  = D_r·ζ_r                                  ← ★ kT가 유도량
D_t = (4/3)a²D_r
u₀  = √(ld2·D_t/τ_r),   f_p = ζ_t·u₀
```

**검산 (`bdkit/units/`가 실행할 것) — 통과 ✅**

```
D_t = (4/3)a²D_r   vs   kT/ζ_t = D_r·ζ_r/ζ_t = D_r·8πηa³/(6πηa) = (4/3)a²D_r    ✓ 항등
수치 (ld2=100):  D_t = 0.01,  kT/ζ_t = 0.01                                      ✓ 일치
```

## 4. 무차원수 원장 ★

| 기호 | 정의 | 의미 | 문헌 범위 |
|---|---|---|---|
| **`Pe`** | `U₀τ_r/σ` = `U₀/(D_rσ)` = `τ_r/(σ/U₀)` | 런 길이 / 입자 크기. **세 가지로 읽힌다** | 2 (Takatori) · 5.77 (Quah `ld2=100`) |
| **`(ℓ/δ)²`** | `U₀²τ_r/D_T` | 런 길이 / **열확산** 길이 | 100 (Quah) |
| `φ` | 2D 면적분율 | | 0.2 (Quah) · **최대 0.83** (Takatori, 유리) |
| `ε/kT` | WCA 세기 | | **500** (Quah) |
| `τ_B/τ_D` | 관성 완화 / 확산 | 오버댐프 타당성 | — |

> **규약 함정 ★** `φ` 정의가 논문마다 다르다.
> Takatori: `φ = nπσ²` (지름 기준) · Quah: `φ = n̄πa²/4`.
> **`bdkit/units/`는 φ 계산 시 지름/반지름 규약을 반드시 기록해야 한다.** 조용히 4배 틀린다.

> **`Pe`와 `(ℓ/δ)²`는 독립 축이다.** `Pe`는 런 길이를 **입자 크기**로, `(ℓ/δ)²`는 **열확산 길이**로
> 잰다. 둘 다 있어야 능동계가 특정된다.

## 7. 적용 게이트 — 이 쌍에서 달라지는 것 ★

| 게이트 | 적용 | 이유 |
|---|---|---|
| 스텝당 확산 변위 `√(2D_tΔt)/σ ≤ 0.03` | ✅ | Quah 실측 0.018σ |
| **스텝당 이류 변위 `u₀Δt/σ`** | ✅ **능동계 전용** | Quah 실측 0.0029σ. 수동계엔 없는 항 |
| **평형화 (`pymbar.detect_equilibration`)** | ❌ **부적합** | **능동계는 열평형에 도달하지 않는다.** 정상상태 판정으로 대체 |
| 자기일관성 `D_msd = kT/γ` | ⚠️ 조건부 | 능동 기여 때문에 장시간 `D_eff = D_t + U₀²τ_r/2`. **자유 확산과 비교하면 틀린다** |
| 유한크기 `L` vs `1.5L` | ✅ | MIPS는 유한크기 효과가 크다 |
| **이분산 강제** | ✅ `φ` 고임계에서 | 안 하면 결정화된 계를 "유리"라 부르게 된다 |

> ### ★ 이 카드가 일반 게이트를 두 개 뒤집는다
> 1. **평형화 게이트가 무의미하다.** 능동계는 평형에 안 간다 → 정상상태 판정으로 교체
> 2. **`D_msd = kT/γ` 자기일관성이 성립하지 않는다.** 능동 기여를 뺀 뒤 비교해야 한다
>
> `05_validation_gates.md`는 게이트를 **계-동역학 쌍별로 켜고 꺼야 한다.**
