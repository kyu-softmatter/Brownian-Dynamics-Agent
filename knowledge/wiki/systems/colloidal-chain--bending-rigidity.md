# `콜로이드 사슬` × `굽힘 강성`

손그림 `inputs/chain-bend-2d-oscill/sketch_01.jpeg` 의 계.
목표는 최종적으로 `G'(ω)`·`G''(ω)` 지만, **먼저 정적 `κ(L)` 을 못 박는다** —
`ω → 0` 극한이 유일한 문헌 대조점이기 때문이다.

> ★ **중심력만으로는 이 계가 성립하지 않는다.** Hard sphere·DLVO·임의의 `U_ij(r_ij)` 는
> 결합각에 복원력을 주지 않으므로 직선 사슬의 굽힘 모드가 zero-energy mode 가 된다
> (`κ₀ = 0`). Pantina & Furst 가 측정한 것이 정확히 이 예측의 반례다.
> 접선 상호작용 = HOOMD 에서는 `md.angle.*` (고정 토폴로지) 또는
> `md.pair.aniso.Patchy*` (결합 생성·파괴 필요할 때).

### 실제 상호작용은 두 방향이고 하나만 쌍포텐셜이다
| 방향 | 무엇 | `U_ij(r)` 로? | 우리 모델 |
|---|---|---|---|
| 법선 | DLVO 의 이중층 반발을 `MgCl₂` 로 차폐 → vdW 최소 → **JKR 접착 접촉** (`a_c ≈ 40–46 nm`) | ✅ | `bond.Harmonic` |
| **접선** | 유한 접촉면의 접촉역학. `W_SL` 로 **접촉선이 핀** 되어 구름·회전에 저항 | ❌ | **`angle.Harmonic`** |

`κ₀ ∝ a_c⁴ ∝ W_SL^{4/3}` — 결합 강성은 접착에너지가 정한다 (Langmuir 논문이 계면활성제로 확인).
`M_c` 초과 시의 접촉선 de-pinning(`≈ a_c` 슬립)은 **우리 모델에 대응물이 없다** — 유효범위 경계다.

## 1. 계 — 상자 안에 무엇이 있는가

| 항목 | 값 |
|---|---|
| 입자 종류 | 단분산 구. 타입 3개: `A`(내부) · `E`(양 끝, **적분 제외**) · `C`(중앙, 하중점) |
| 차원 | 2D |
| 상호작용 | `bond.Harmonic`(`r0=σ`) + **`angle.Harmonic`(`t0=π`)** ← 굽힘의 본체 |
| 다분산 | 단분산 |
| 경계 | 주기. 상자는 사슬 길이의 4배 (최소이미지로 끝-끝이 잘못 이어지는 것만 막으면 됨) |
| 용매 | 암묵적 free-draining (`γ` 등방, HI 없음) |

**거리 구속을 쓰지 않는다** — `Brownian` 과 호환 불가.

## 2. 목적 동역학 — 무엇을 보는가

| | |
|---|---|
| 묻는 질문 | 사슬 길이 `L` 에 따라 점하중 강성 `κ` 가 어떻게 변하나 → `κ ~ L^-3` 인가 |
| 평형/비평형 | 둘 다 지원. `static`=결정론 이완(`kT=0`) · `thermal`=평형 요동 |
| 정상상태 있음? | `static` 은 고정점(이완 완료), `thermal` 은 평형 |

## 3. 기준 단위 ★ — 이 쌍에서만 유효하다

| 차원 | 선택 | 왜 이것인가 |
|---|---|---|
| 길이 | **`σ = 2a` = 결합 길이** | 사슬 토폴로지가 접촉으로 정해진다. `L = (N-1)σ` 가 스팬 |
| 에너지 | `kT` | |
| 시간 | **`τ_κ = γ/κ(L)`** ← 트랩의 `τ_trap` 대응물 | 하중점 응답 시간 |

> ★ **`τ_κ` 는 이 계의 완화시간이 아니다.** 실측 완화시간은
> `τ_relax = 0.478 L τ_κ` 이고, 즉 `τ_relax ∝ L⁴`. 사슬 전체를 끌어야 하기 때문이다.
> **`τ_κ` 로 런 길이를 잡으면 긴 사슬에서 이완이 안 끝난다** —
> 2026-07-28 에 고정 길이 `30 τ_κ` 로 돌려 `N=41` 에서 `κ` 가 22 % 높게 나왔다.
> ⇒ **런 길이는 `τ_relax` 기준으로 잡거나 적응형 수렴 판정을 쓴다.**
> 기본모드 이론 `τ₁ = γL⁴/(π⁴EI)` → `τ_relax/τ_κ = 48/π⁴ = 0.4928`, 실측 `0.478` (3 %).

## 4. 무차원수 원장 ★

| 기호 | 정의 | 의미 | 범위 |
|---|---|---|---|
| `N` | 입자 수 (**홀수**) | 중앙 입자가 정의되어야 3점 굽힘이 성립 | 5 – 41 (검증) |
| `L*` | `(N-1)` | 스팬 [σ] | 4 – 40 |
| `k_θ*` | `k_θ/kT` | 각 스프링. `EI* = k_θ* · b*`, `b*=1` | `1e4` (검증) |
| `κ*` | `κσ²/kT` | 점하중 강성 | `7.5 – 7500` |
| **`C`** | `k_bond*/κ*` | 신축 여유비. **`k_bond` 를 상수로 두면 스텝 수가 `L³` 로 늘어난다** | `100` (미수렴검사) |
| `δ/L` | 처짐 비 | 선형 유지 조건 | `≤ 0.01` |

## 6. 관측량

| 관측량 | 오차 산출 | 비고 |
|---|---|---|
| `κ` (static) | **없음 — 결정론** | 대신 `converged` 플래그 + Aitken 외삽 `κ_∞` 로 이완 완료를 증명 |
| `κ` (thermal) | 시드 4개 산포. 런내 SE 는 적분 자기상관(Sokal) | 등분배 `⟨y_c²⟩ = kT/κ` |
| `τ_relax` | 이완 곡선 지수 적합 | `L⁴` 스케일링 확인용 |
| `G'(ω), G''(ω)` | 미착수 | 진동 구동 필요 |

## 7. 적용 게이트

| 게이트 | 적용 | 이유 |
|---|---|---|
| 스텝당 확산 변위 `√(2Δt*) ≤ 0.03` | ✅ | thermal 만 의미 (static 은 `kT=0`) |
| 힘 변위 `max|F*|Δt* ≤ 0.005` | ✅ **단 불충분** | **곧은 사슬은 `max|F*| = 0` 이라 무력하다** |
| **안정성 `Δt* ≤ 0.2·2/(4k_bond*+16k_θ*)`** | ✅ **거의 항상 binding** | 명시적 오일러 강성 불안정. [[dt-gate-needs-a-stability-term-for-stiff-bonds]] |
| **결합 길이 `max|d-σ|/σ ≤ 0.05`** | ✅ **필수** | `check_finite` 는 폭발을 못 잡는다 (`1.4e7` 도 유한) |
| 이완 수렴 (static) | ✅ | 고정 길이 금지 — `τ_relax ∝ L⁴` |
| 평형화 (`pymbar`) | ❌ | static 은 평형이 아니라 고정점 |
| 통계량 요동 | ✅ thermal | `guards.assert_statistic_fluctuates` |
