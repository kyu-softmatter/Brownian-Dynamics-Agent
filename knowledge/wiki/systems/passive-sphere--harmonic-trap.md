# 수동 구형 × 조화 트랩

광집게(또는 임의의 조화 구속)에 갇힌 수동 구형 입자의 과감쇠 BD.
`U(r) = ½ k r²`, `r² = Σ_{i<d} x_i²`

> **이 카드가 존재하는 이유:** `τ_D = σ²/D₀`를 기준 시간으로 강요하면 이 계를 볼 수 없다.
> 첫 런에서 `τ_D/τ_trap = 2.4 × 10⁵`가 관측되었다 — 자세히 §3.

---

## 1. 언제 이 카드인가
- 입자가 **위치 의존 조화 퍼텐셜**에 갇혀 있다 (광집게, 자기 트랩, 음향 트랩)
- 목적 동역학이 **구속 내 요동**이다 (탈출·수송이 아니라)
- 트랩 중심이 정지 상태 (진동 트랩은 별도 카드: `--oscillating-trap`)

**이 카드가 아닌 경우**
- 트랩 배열 속 수송·분산 → Barakat 2022 계열, `--trap-array-dispersion` (미작성)
- 트랩 탈출(활성력 vs 구속력) → `abp--trap-escape` (미작성)
- 다체 유체동역학 측정 → Kim 2025 계열, HI 필수 → v1 범위 밖

## 2. 지배 방정식
```
과감쇠 Langevin:   gamma dr/dt = -k r + sqrt(2 kT gamma) xi(t)
                   <xi_i(t) xi_j(t')> = delta_ij delta(t-t')
```
질량은 동역학에 들어오지 않는다 (과감쇠). HOOMD 입력에는 필요하므로 `1`로 둔다.

## 3. ★ 기준 단위 — `(ℓ_trap, kT, τ_trap)`

| 척도 | 선택 | 값 |
|---|---|---|
| 길이 | **`ℓ_trap`** | `sqrt(kT/k)` — 열요동이 도달하는 거리 |
| 에너지 | `kT` | |
| 시간 | **`τ_trap`** | `gamma/k` — 구속 완화시간 |

이 선택 하에 운동방정식이 **파라미터 없이** 정규화된다:
```
dr*/dt* = -r* + sqrt(2) xi(t*)        ⇒  D* = 1,  k* = 1,  <x*^2> = 1
```
`simbot.units.scales_harmonic_trap()` 이 이 척도를 만든다.

### 왜 `τ_D`가 아닌가 — 실측 근거
```
tau_trap / tau_D  =  kT / (k sigma^2)  =  1 / k*_sigma
```
`k*_σ ≫ 1`(강한 트랩)이면 `τ_trap ≪ τ_D`다. 첫 런(`a=5 μm`, `k=10 pN/μm`, `T=300 K`)에서:

| | 값 |
|---|---|
| `τ_D = σ²/D₀` | `1947 s` (32.5 분) |
| `τ_trap = γ/k` | `8.06 ms` |
| **비** | **`2.414e5`** |

> `τ_D` 기준으로 `dt* = 5e-5`를 쓰면 **`dt = 97 ms = 12 × τ_trap`.**
> **발산하지 않는다** — 그래서 위험하다. 완화 과정을 통째로 건너뛰고도 그럴듯한 숫자가 나온다.
>
> BD_agent가 경고한 "트랩 계에서 `Δt`가 완화시간의 54배"([[dt-gate-should-be-displacement-based]])가
> 여기서 `2.4×10⁵`배 규모로 재현되었다.

`Δt/τ_D`는 다른 논문과 비교하기 위해 **기록만** 한다.

## 4. 무차원수 원장

| 기호 | 정의 | 의미 | 레짐 |
|---|---|---|---|
| **`k*_σ`** | `k σ² / kT` | 트랩 강성 (입자 크기 기준) | `≫1` 강한 구속 → **배제부피 무관** |
| **`ℓ_trap/σ`** | `sqrt(kT/k)/σ = 1/sqrt(k*_σ)` | 입자가 자기 지름의 몇 배를 탐색하나 | `≪1`이면 단일입자 문제 |
| `τ_D/τ_trap` | `= k*_σ` | 시간척도 분리 | `≫1`이면 `τ_trap` 필수 |
| `dt*` | `Δt/τ_trap` | 적분 해상도 | §7 게이트 |
| `τ_i/τ_trap` | `m/(γ τ_trap)` | 과감쇠 타당성 | **`≪1` 필수** |
| `Re` | `ρ v a/η`, `v ~ ℓ_trap/τ_trap` | Stokes 타당성 | **`≪1` 필수** |
| `f/f_c` | `f_c = k/(2πγ)` | 코너주파수 기준 주파수 | 미세유변학 대조 |

**여기서 의미 없는 것:** `φ`(단일입자), `T* = kT/ε`(쌍 상호작용 없음), `Pe`(구동 없음)

## 5. 해석해 — 전부 정확해, 근사 없음

`d` = 트랩이 작용하는 차원 수

| 양 | 식 | 무차원 |
|---|---|---|
| 성분별 등분배 | `<x_i^2> = kT/k` | `1` (`d` 무관) |
| 반경 제곱 | `<r^2> = d kT/k` | `d` |
| MSD | `<\|dr(t)\|^2> = 2d (kT/k)(1 - e^{-t/tau_trap})` | `2d(1-e^{-t*})` |
| MSD plateau | `2d kT/k` | `2d` |
| 완화시간 | `tau_trap = gamma/k` | `1` |
| 코너주파수 | `f_c = k/(2 pi gamma)` | `1/2pi` |
| 위치분포 (성분) | Gaussian, `sigma = sqrt(kT/k)` | `N(0,1)` |
| 위치분포 (반경, 2D) | Rayleigh, 최빈값 `sqrt(kT/k)` | 최빈값 `1` |
| 속도자기상관 | `<r(0)·r(t)> = d(kT/k) e^{-t/tau_trap}` | `d e^{-t*}` |

### ★ Euler–Maruyama의 계통편향 — 정확히 알려져 있다
```
스킴:      x_{n+1} = x_n (1 - dt*) + sqrt(2 dt*) xi
정상분산:  Var* = 1/(1 - dt*/2)          (정확, 근사 아님)
상대편향:  dt*/2 / (1 - dt*/2)  ~  dt*/2
```
| `dt*` | 편향 |
|---|---|
| `2e-2` | `+1.010 %` |
| `1e-2` | `+0.503 %` |
| `5e-3` | `+0.251 %` |
| `1e-3` | `+0.050 %` |

> **이 카드의 가장 강한 검증 도구다.** 측정 `⟨x*²⟩`가 `1.0000`이 나오면 **실패 신호**다 —
> 편향이 사라졌다면 적분 스킴이 다르거나 `k`·`τ_trap` 입력이 틀렸다는 뜻이다.
> **알려진 오차를 재현하는 것이 알려진 값을 재현하는 것보다 강한 검증이다.**
> 구현: `simbot.estimators.euler_maruyama_trap_variance_bias`

## 6. 관측량

| 관측량 | 방법 | 무엇을 검증하나 |
|---|---|---|
| `⟨x_i²⟩` 성분별 | 히스토그램 2차 모멘트 | **`k`, `T`만.** `η`·`a`와 완전 무관 |
| `⟨r²⟩` | 반경 분포 | **차원 `d`** — `d`에 정비례 |
| MSD(t) | 시간원점 평균 + 블록평균 오차 | plateau(→`d`), 완화시간(→`η`,`a`) |
| `τ_trap` 피팅 | MSD 또는 위치 자기상관 지수 피팅 | **`η`, `a`** |
| 위치분포 정규성 | KS test vs Gaussian/Rayleigh | 비가우시안 인공물 |
| `k` 되찾기 | `k = kT/⟨x²⟩` | 자기일관성 |
| PSD | 위치 파워스펙트럼 → Lorentzian, 코너 `f_c` | 광집게 실험과 직접 대조 가능한 형태 |

### ★ 정적/동적 측정의 직교성 — 이 카드의 핵심 효용
```
<x^2> = kT/k            ← k, T 에만 의존.   eta, a 에 완전 무관
tau_trap = 6 pi eta a/k ← eta, a 에 의존
```
> **`η`를 가정으로 채웠어도 `⟨x²⟩` 예측은 전혀 영향받지 않는다.**
> 감도 분석(S7b)에서 `∂ln⟨x²⟩/∂ln η = 0` 이 **해석적으로** 보장된다 — 런이 필요 없다.
> 반대로 `τ_trap`은 `η`·`a`를 검증하는 유일한 창이다.

## 7. 적용 게이트 — 켜고 끄기

| 게이트 | 이 카드에서 | 이유 |
|---|---|---|
| 평형화 판정 | ✅ **유효** | 열평형에 도달한다. `t_equil ≳ 10 τ_trap` |
| 자기일관성 `D_msd = kT/γ` | ⚠️ **단시간만** | `t ≪ τ_trap`에서만 자유확산. 장시간엔 plateau |
| 등분배 `⟨x²⟩ = kT/k` | ✅ **필수 · 1급 게이트** | 이 카드의 주 검증 |
| **스텝당 변위 vs `σ`** | ❌ **끔** | 쌍 상호작용이 없으므로 겹침이 없다. `ℓ_trap/σ ~ 1e-3`이라 무의미 |
| **`dt* = Δt/τ_trap`** | ✅ **필수 · 이것이 진짜 게이트** | `dt* ≤ 1e-2` (편향 `≤0.5 %`). 안정성 한계는 `dt* < 2` |
| EM 편향 재현 | ✅ **필수** | `⟨x*²⟩ = 1/(1−dt*/2)` 확인 |
| 과감쇠 `τ_i/τ_trap` | ✅ 필수 | `≪1` |
| `Re` | ✅ 필수 | `≪1` |
| 유한크기 `L` | ⚠️ **약함** | 박스는 `≫ ℓ_trap`이면 되고, `ℓ_trap`이 nm 규모라 자동 만족 |
| `r_cut ≤ L/2` | ❌ 해당 없음 | 쌍 포텐셜 없음 |
| 이분산 강제 | ❌ 해당 없음 | 상호작용 없어 결정화 불가 |
| HI 무시의 영향 | ✅ **무해** (단일입자) | 벽이 멀면 무한매질 Stokes가 정확. 다체는 Kim 2025 → 카드 밖 |
| **★ 상수-`γ` Stokes 타당성** | ⚠️ **`a` 에 강하게 의존** | `a ≳ 5 μm` 에서 Basset(`4.3 %` @ `f_c`)·Faxén(`h=10a` 에서 `2.3배`)·중력(`ℓ_trap/ℓ_g = 1.35`)이 통계오차를 넘는다. `a ≲ 2 μm` 면 전부 작다 → [[stokes-drag-corrections]] |
