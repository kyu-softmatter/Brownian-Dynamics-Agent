> **진동시킨다.** `x`(좌우) · `y`(상하) · **대각선(결정면 방향)** 으로 흔들며
> `G'(ω)`, `G''(ω)` 를 잰다.

## 1. 계

자매 카드 §1 과 **동일하다** (`N≈300`, `σ=10 μm`, 2D, `k_t=10 pN/μm`).
같은 빈칸을 공유한다: **쌍 상호작용 미정 (A1)**, **격자상수 미정 (A2)**.

## 2. 목적 동역학

| | |
|---|---|
| 묻는 질문 | **`G'(ω)`·`G''(ω)` 가 구동 **방향**에 의존하는가** (`x` / `y` / 대각선) |
| 구동 | `r_trap(t) = r₀ + a sin(ωt) ê`, `ê ∈ {x̂, ŷ, 대각}` |
| 스윕 | `ω` (주파수 스캔) × `ê` (3 방향) × `a` (진폭 — 선형성 확인용) |
| 평형/비평형 | **주기적 정상상태** (periodic steady state). 등속 구동과 달리 결함이 무한 축적되지 않을 수 있다 |

## 3. 기준 단위 ★ — 자매 카드와 **같다**

| 차원 | 선택 |
|---|---|
| 길이 | 격자상수 `d` |
| 에너지 | `kT` |
| 시간 | `τ_d = d²/D₀` |

### ★ 이 카드가 카드 체계에 대해 알려주는 것

**기준 단위가 자매 카드와 동일하다.** `(계 × 목적동역학)` 카드의 표준 정당화는
"목적동역학마다 기준 시간이 다르다"였는데 **여기서는 다르지 않다.**

그래도 카드를 나누는 것이 옳다. 갈리는 것은:

| | 등속 구동 | 진동 구동 |
|---|---|---|
| 지배 무차원수 | `Pe_d = vd/D₀` | **`ωτ_trap`, `a/d`** |
| 정상상태 | 비평형 정상상태 | **주기적** 정상상태 |
| 관측량 | 항력·일·결함 축적 | **`G'`, `G''`** (응답의 진폭·위상) |
| 평형화 판정 | 구동 후 무의미 | **주기 평균**으로 판정 |
| 선형성 검사 | 해당 없음 | ✅ **필수** (`a` 스윕) |

⇒ **카드의 단위는 "척도가 다른 쌍"이 아니라 "게이트·관측량이 다른 쌍"이다.**
`master_plan.md` §5·§10.3 의 서술을 이 사례로 넓혀야 한다 (아직 안 함).

## 4. 무차원수 원장 ★

`d = 3σ` 가정. 확정 전 근거로 쓰지 말 것.

| 기호 | 정의 | 의미 | 비고 |
|---|---|---|---|
| **`ωτ_trap`** | `ω γ/k_t` | 프로브가 트랩을 따라가는가 | `≪1` 준정적 · `≫1` 위상 지연 |
| `ωτ_d` | `ω d²/D₀` | 격자 확산 대비 구동 주파수 | 스윕의 진짜 축 |
| **`a/d`** | 진폭 / 격자상수 | **선형성** | `≪1` 선형 · `~1` 이면 결함 생성 |
| `a/ℓ_trap` | 진폭 / 열변위 | 신호가 잡음보다 큰가 | **`≫1` 이어야 측정 가능** |
| `Γ` | 쌍 상호작용 세기 | 결정성 | `> 59.88` 필요 (A1) |
| `θ` | 구동 방향 vs 결정면 | **이 카드의 주인공** | `0°`(근접충전 방향) · `30°` · 그 사이 |

## 5. ★ 사전 예측 — 2D 육방 격자의 선형 탄성은 **등방이다**

> **대칭성 논증 (문헌 인용 아님 — 유도 가능한 사실):** 2D 에서 4계 탄성 텐서가
> 60° 회전에 대해 불변이면 독립 성분이 **2개**로 줄어들고, 그것은 등방 고체와 같은 형태다.
> 3겹 이상의 회전 대칭을 가진 2D 격자는 **탄성적으로 등방**이다.

⇒ **선형 응답 영역(`a/d ≪ 1`)에서 `G'`·`G''` 는 구동 방향에 의존하지 않아야 한다.**

이것이 이 카드의 가장 값진 사전 예측이다. 방향 의존성이 관측되면 셋 중 하나다:

| 관측 | 해석 |
|---|---|
| 작은 `a/d` 에서 방향 의존 | ⚠️ **유한 크기 또는 경계 인공물** — `N` 을 늘려 사라지는지 확인 |
| 큰 `a/d` 에서 방향 의존 | ✅ **비선형/항복** — 물리다. 근접충전 방향으로 슬립이 쉽다 |
| 결함 생성 경로가 방향 의존 | ✅ **물리다.** 전위 글라이드는 결정면을 따른다 |

★ **따라서 이 실험의 설계는 `a` 스윕을 반드시 포함해야 한다.** `a` 하나로 3방향만
비교하면 "등방이어야 하는데 다르다"와 "비선형이라 다르다"를 구별할 수 없다.

> ⚠️ 이 예측은 **연속체 탄성**에 대한 것이다. `G'`·`G''` 를 **프로브 응답**에서 뽑을 때는
> 프로브 주변의 국소 구조(어느 방향에 이웃이 있는가)가 개입할 수 있고, 그것은 격자
> 대칭성과 별개다. 프로브 척도(`σ`)와 격자 척도(`d`)가 가까우면 더 그렇다 (A2 가 중요).

## 6. 관측량

| 양 | 어떻게 | 상태 |
|---|---|---|
| 프로브 변위 응답 `x(t)` | 궤적 | ✅ |
| 트랩 힘 `F(t) = k_t(r_trap − r_probe)` | 직접. **비리얼 불필요** | ✅ 안전 |
| **복소 응답 `χ(ω)`** | `x(ω)/F(ω)` — 진폭비와 위상차 | ⛔ `analysis/microrheo.py` 없음 |
| **`G'`, `G''`** | 능동 미세유변학 관계식 | ⛔ 미구현. **관계식 선택이 미결 (A7)** |
| 방향별 `ψ₆`, 결함 | Voronoi (`freud`) | ⛔ `analysis/structure.py` 없음 |
| 응력 텐서 | 비리얼 | ⛔ **차단** → [[external-field-virial-convention]] |

### ⚠️ A7 — `G*` 를 뽑는 관계식이 자명하지 않다

수동 미세유변학의 GSER([[1995-mason-weitz-gser-microrheology]])은 **열요동만** 쓰는
3D 관계식이다. 이 계는 ① 능동 구동 ② 2D ③ 결정(고체)이다. 셋 다 GSER 의 전제와 다르다.

- **2D**: `G` 의 차원이 3D 와 다르다 (2D 는 `N/m`, 3D 는 `Pa`). 환산에 두께 가정이 필요하다
- **능동**: 응답함수 `χ(ω)` 를 직접 재므로 오히려 깨끗하다. `G* ~ 1/(C·a·χ)` 형태이지만
  **`C` 가 2D 에서 무엇인지 확인 필요**
- **고체**: `G'` 가 `ω→0` 에서 유한한 값(항복강도 아래)으로 가야 한다. 액체면 `G'→0`

⇒ **문헌 근거를 먼저 확보해야 한다.** `knowledge/source/papers/` 에 2D 능동
미세유변학 항목이 없다. 새로 넣은 논문 2편이 관련될 수 있다 (미확인).

## 7. 적용 게이트

자매 카드 §7 을 상속하되 다음이 다르다:

| 게이트 | 이 카드에서 | 이유 |
|---|---|---|
| **선형성 (`a` 스윕)** | ✅ **필수 · 1급 게이트** | §5 의 예측을 검증하려면 선형 영역을 확인해야 한다 |
| **주기 정상상태 판정** | ✅ 필수 | 여러 주기에 걸쳐 응답이 반복되는가. 초기 과도를 버려야 한다 |
| **`ωΔt ≪ 1`** | ✅ **필수 — 새 게이트** | 한 주기를 최소 `~100` 스텝으로 분해해야 위상이 나온다. 고주파에서 이것이 `dt` 를 지배할 수 있다 |
| `a/ℓ_trap ≫ 1` | ✅ 필수 | 신호가 열요동보다 커야 한다. 자매 카드 §9 의 SNR 논의와 같은 부류 |
| 등속 정상상태 판정 | ❌ 해당 없음 | 주기 구동이다 |
| 결함 축적 | ⚠️ 약함 | 주기 구동은 결함을 축적하지 않을 수 있다 (되돌아온다) |
