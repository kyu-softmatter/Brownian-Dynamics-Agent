# 상수-`γ` Stokes 항력의 한계 — 언제 우리 정밀도를 넘는가

## 요약

과감쇠 BD 에서 `γ` 는 "고려 사항"이 아니라 **동역학 전부**다 — `D₀ = kT/γ` 외에 다른
동역학 파라미터가 없다 (질량은 들어가지 않는다).

그런데 **시뮬레이션 안에서 `η` 는 등장하지 않는다.** 축약 단위로 `γ* = 1` 로 돌고,
`η` 는 물리 단위 환산 **1회**에만 쓰인다. 대부분의 BD 논문이 `η` 를 아예 적지 않고
전부 `τ_D` 로 보고하는 이유가 이것이다.

**진짜 문제는 상수-`γ` 자체다.** `a` 가 크면 세 보정이 통계오차를 넘는다.

## 근거 — `a = 5 μm`, `k = 10 pN/μm`, `T = 300 K`, 물 (첫 손그림 계)

우리 통계오차: **0.6 %** (시드 4개).

### ① 비정상 항력 (unsteady / Basset)
```
gamma(w) = 6 pi eta a (1 + a/delta),    delta = sqrt(2 eta / (rho w))
```
`δ` = 점성 침투깊이. 진동수가 높으면 유체가 따라오지 못해 항력이 커진다.

| `f` [Hz] | `δ` [μm] | `a/δ` = `γ` 보정 |
|---|---|---|
| 1 | 523 | 0.96 % |
| **19.74** (`f_c`) | 118 | **4.25 %** ← 통계오차의 7배 |
| 100 | 52 | 9.6 % |
| 1 000 | 16.5 | 30 % |
| 10 000 | 5.2 | 96 % |

**함의:** 우리 모델은 Markovian(상수 `γ`)이므로 이 효과를 **원리적으로 재현하지 못한다.**
실제 유체는 MSD 단시간에 `t^{1/2}` 보정을, PSD 에 순수 Lorentzian 이탈을 준다.
관련 시간척도: `τ_vorticity = a²ρ/η = 29 μs`.

### ② 벽 근접 (Faxén)
```
gamma_perp / gamma_0  ~  (1 - 9a/8h)^-1        h = 입자 중심-벽 거리
```
| `h` [μm] | `h/a` | `γ_⊥/γ₀` | `τ_trap` [ms] |
|---|---|---|---|
| 7.5 | 1.5 | 4.00 | 32.3 |
| **10** | 2 | **2.29** | **18.4** |
| 25 | 5 | 1.29 | 10.4 |
| 50 | 10 | 1.13 | 9.1 |
| 100 | 20 | 1.06 | 8.6 |

> **광집게 실험은 보통 커버슬립 근처다.** `h = 10 μm` 면 `τ_trap` 이 **2.3배**.
> 이것이 실험 대조에서 가장 큰 오차원이 될 수 있다.
> 다체 HI 실측은 [[2025-kim-manybody-hydrodynamics-optical-tweezers]] 참조 (`reproduced: no`).

### ③ 중력 — 트랩 계에서 놓치기 쉽다
폴리스티렌 `ρ = 1050` in 물:

| 양 | 값 |
|---|---|
| 부력 보정 무게 `W = Δρ V g` | **`0.275 pN`** |
| `ℓ_trap` 에서의 트랩힘 `k ℓ_trap` | **`0.204 pN`** ← 같은 자릿수 |
| 침강길이 `ℓ_g = kT/W` | **`15.08 nm`** |
| `ℓ_trap = √(kT/k)` | **`20.35 nm`** |
| **`ℓ_trap/ℓ_g`** | **`1.35`** ← `>1` 이면 무시 못 함 |
| 중력 처짐 `z₀ = W/k` | **`27.5 nm` = `1.35 ℓ_trap`** |

> **처짐이 열요동보다 크다.** 2D **수평**면이면 중력이 면 수직이라 면내 동역학과 무관하지만,
> **수직면이었다면 중력이 지배한다.** 트랩 계에서 "2D 평면의 방향"이 물리적으로 중요해지는
> 이유가 이것이다 — 첫 런에서 사용자가 2D 를 확인한 것이 우연히 이 문제를 비껴갔다.

## 세 보정이 모두 `a` 때문이다

| 보정 | `a` 스케일링 |
|---|---|
| Basset `a/δ` | `∝ a` (그리고 `f_c ∝ 1/a` 이므로 `f_c` 에서는 `∝ a^{3/2}`) |
| Faxén `9a/8h` | `∝ a` |
| 중력 `ℓ_trap/ℓ_g = W/(k ℓ_trap)` | `∝ a³` |
| `ℓ_trap = √(kT/k)` | **`a` 무관** |

`a = 5 μm → 1 μm` (같은 `k`):

| | `a = 5 μm` | `a = 1 μm` |
|---|---|---|
| `f_c` | 19.7 Hz | 98.7 Hz |
| Basset @ `f_c` | **4.25 %** | 1.9 % |
| `ℓ_g` | **15.1 nm** | 1902 nm |
| `ℓ_trap/ℓ_g` | **1.35** | **0.011** (무시 가능) |

> **광집게 전형 크기(`0.5–2 μm`)에서는 세 보정이 모두 작다.**
> `a = 5 μm` 는 광집게로 큰 입자이고, 그래서 이 계가 보정에 민감하다.

## 적용 범위 / 한계

**상수-`γ` Stokes 를 믿어도 되는 조건**
- `a ≲ 2 μm` (광집게 전형 크기)
- 벽에서 `h ≳ 10a`
- 관심 주파수 `f ≪ η/(ρa²)` — 즉 `a/δ ≪ 1`
- 수평면 또는 `ℓ_g ≫ ℓ_trap`

**깨지는 조건 (위 계가 전부 해당)**
- `a ≳ 5 μm` + 벽 근처 + `f_c` 근처 스펙트럼

## 무엇을 하면 되나

| 문제 | 처방 | 구현 난이도 |
|---|---|---|
| Faxén | `γ` 를 상수 대신 `γ(h)` 로 — 벽 거리에 의존 | 쉬움 (`γ` 재계산) |
| 중력 | `md.force.Constant` 로 균일 힘 추가 | 쉬움 |
| Basset | **Markovian BD 로는 불가.** GLE(일반화 Langevin) 또는 유체 결합 필요 | 어려움 — v1 범위 밖 |

> **Basset 항이 v1 의 근본적 한계다.** `HI 무시`([[no-hydrodynamics]])와 성격이 같다 —
> 이동도를 상수로 두는 것 자체의 대가다. 다만 HI 는 **입자 간** 효과이고
> Basset 은 **단일 입자**에도 나타난다.
