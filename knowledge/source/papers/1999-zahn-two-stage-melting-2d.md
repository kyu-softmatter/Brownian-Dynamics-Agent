# Two-Stage Melting of Paramagnetic Colloidal Crystals in Two Dimensions

## 왜 이 위키에 있는가

★ **우리 `pair_repulsive` 계의 문헌 대조 원출처.** 같은 퍼텐셜(`1/r³`), 같은 차원(2D),
같은 무차원수(`Γ`)다. `benchmarks.yaml` 의 증거 층 ③(문헌)을 처음 채우는 항목이다.

`configs/step4/*.yaml` 이 처음부터 `Γ_Zahn = π^1.5·A` 를 계산해 두었지만 **그 환산의
근거가 이 논문에 있는지 확인되지 않은 상태였다** (`benchmarks.yaml` 의 `blocked:` 항목).
이 증류가 그것을 닫는다 — **환산은 맞다** (§2).

`Received 5 October 1998` · PACS 64.70.Dv, 61.72.Lk, 82.70.Dd

## 1. 계 — 우리와 무엇이 같고 무엇이 다른가

| | Zahn 1999 | 우리 (`pair_repulsive`) |
|---|---|---|
| 퍼텐셜 | `U(r) = (μ₀/4π)M²/r³` 자기 쌍극자 반발 | `U(r) = A·k_BT/r³` **같은 형태** |
| 차원 | 준2D — 면외 운동이 지름의 **<1%** | 엄격 2D (`Lz=0`) |
| 무차원수 | `Γ` (§2) | `A` = `Γ/π^1.5` |
| 입자 | Dynabeads M-450, 지름 4.7 µm, Fe₂O₃ 도핑 초상자성 | 반지름 2.25 µm (지름 4.5 µm) |
| 매질 | 물/공기 계면 (원통 액적, 중력 구속) | 벌크 물 (`η`=1e-3) |
| 계 크기 | 시야 520×440 µm²에 **~10³개**, 전체 시료 ~10⁵개 | `N`=780 |
| 평형화 | **며칠~일주일** (고자기장 결정상) + 온도 단계마다 ~1시간 | **10 `τ_d`** |
| HI | 있다 (계면 유체) | 없다 (free-draining, `D11`) |
| 결함 제거 | ac 자기장으로 어닐 → 단결정 도메인 하나 (수천 개당 전위 1개) | 없음 |

**평형화 시간 차이가 가장 크다.** 우리 10 `τ_d` 와 저쪽 며칠은 비교 대상이 아니다 —
`SQ13`(두 시작이 안 만났다)이 놀랍지 않은 이유가 여기 있다.

**입자 크기가 우연히 거의 같다** (4.7 vs 4.5 µm). 다만 이 계는 scale-free 라
반지름은 시간 단위만 정하고 무차원 궤적을 안 바꾼다 — 우연이 이득을 주지는 않는다.

## 2. ★ `Γ` 의 정의 — 우리 환산이 맞다

본문 p.2721 우측 단, verbatim:

> "absolutely calibrated by the dimensionless interaction amplitude (or inverse temperature)
> **`Γ = (μ₀/4π)(χ_eff B)²(πn)^{3/2}/kT`** (`n` denotes the 2D volume fraction of the particles)"

`M = χ_eff B` 이고 `χ_eff = (7.62 ± 0.2) × 10¹¹ A m²/T`. 그리고 **`T ≡ 1/Γ`** —
`Γ` 가 곧 역온도라 논문 전체가 `1/Γ` 를 온도로 쓴다.

### 우리 `A` 와의 환산 — 유도

```
U(r) = (μ₀/4π)M²/r³                        쌍극자 반발
A    ≡ U(d)/k_BT,   d = L/√N               우리 정의 (d = 평균간격)
n    = N/L² = 1/d²                         면수밀도
(πn)^{3/2} = π^{3/2}/d³
Γ = (μ₀/4π)M²·π^{3/2}/(k_BT·d³) = π^{3/2}·U(d)/k_BT = π^{3/2}·A
```

**`π^{3/2} = 5.5683`** — `configs/step4/*.yaml` 의 주석 `5.568` 과 일치한다. ✓

### ⚠ 논문의 `n` 표기는 느슨하다

논문은 `n` 을 *"2D volume fraction"* 이라 적었는데, **`(πn)^{3/2}` 가 `1/길이³` 이 되려면
`n` 은 면적분율(무차원)이 아니라 면수밀도 `[1/길이²]` 여야 한다.** 차원해석이 강제한다.
우리 환산은 면수밀도로 읽은 것이고, 그 읽기에서만 `π^{3/2}` 가 나온다.

면적분율로 읽으면 `Γ` 가 무차원 세제곱이 되어 퍼텐셜 단위와 안 맞는다 — 그래서
**이건 해석의 여지가 아니라 논문의 용어 실수로 판단한다.** 다만 판단이므로 적어 둔다.

## 3. ★ 전이값 — `benchmarks.yaml` 의 `expected`

두 전이 모두 **절대값**으로 주어진 것이 이 논문의 기여다 (초록: *"The absolute values of
the transition temperatures are given"*).

| 전이 | `1/Γ` (본문) | `Γ` | 판정 기준 |
|---|---|---|---|
| 결정 → hexatic (`m`) | **0.0167** | **59.88** | Lindemann `γ_M` 이 임계값 `γ_c^M = 0.033` 과 교차 |
| hexatic → 등방액체 (`i`) | **0.0179** | **55.87** | `g₆(r)` 가 `r^{−1/4}` 보다 빨리 감쇠하기 시작 |

즉 **`Γ > 59.9` 결정 · `55.9 < Γ < 59.9` hexatic · `Γ < 55.9` 등방액체.**

> `Γ_m > Γ_i` 인 것이 헷갈리기 쉽다 — `Γ` 는 **역온도**라 클수록 차갑다. 가열하면
> `Γ` 가 내려가며 결정 → hexatic → 액체 순으로 간다.

### 관측된 네 상태 (본문 p.2722–2723)

| `1/Γ` | `Γ` | 상 | 근거 |
|---|---|---|---|
| 0.0151 | 66.2 | 결정 | `g_G` 대수감쇠 · `g₆` 유한 · `γ_L` 유계 · **결함 0** |
| 0.0164 | 61.0 | 결정 (융해 직전) | `η ≈ 0.33` (예측값과 일치) · 전위쌍이 풀리기 시작하나 수초 내 소멸 |
| 0.0177 | 56.5 | **hexatic** | 자유전위 존재 · `g_G` 단거리 · `g₆` 준장거리(대수) · disclination 생성되나 소멸 |
| 0.0189 | 52.9 | 등방액체 | **자유 disclination 안정** · `g_G`·`g₆` 둘 다 지수감쇠 |

### 부수 정량값

| 양 | 값 | 비고 |
|---|---|---|
| `η(T_m)` | **0.33** | `g_G ~ r^{−η}` 의 융해점 지수. `η = (G²a²/64π²)(1+σ_R)(3−σ_R)` 에서 계산 |
| `η₆` | 전이에서 **→ 1/4** | `g₆ ~ r^{−η₆}`, hexatic→액체 경계 |
| `γ_c^M` | **0.033** | Lindemann 임계값. Bedanov & Gadiyak (Phys. Lett. **109A**, 289 (1985)) |
| `D₀` | 0.1 µm²/s | 개별 입자 확산 |
| `D_dis` | `≈ 100 × D₀` | **전위의 확산.** 열평형 도달 시간을 정하는 것이 이쪽이다 |
| 격자상수 `a` | 13.8 → 25.4 µm | 계 크기를 3배 이상 줄여도 전이 불변 |

> `γ_c^M = 0.033` 은 **격자상수 규약에 의존한다.** 각주 [16]: Bedanov & Gadiyak 은 다른
> 규약을 써서 `0.12` 를 얻었다. 이 수를 인용할 때 규약을 함께 옮기지 않으면 3.6배 틀린다.

## 4. 이 논문이 명시적으로 배제한 것

우리가 같은 주장을 하려면 같은 것을 배제해야 한다.

- **계 크기 의존성 없음** — `a` 를 13.8→25.4 µm 로 늘려 입자 수를 3배 이상 줄였는데
  `γ_M` 곡선들이 `1/Γ` 함수로 **하나의 master curve 로 붕괴**했다 (Fig. 4).
- **가열속도 의존성 없음** — 두 가열속도에서 `ξ_G`, `ξ₆` 의 역수가 같은 전이온도를 준다
  (Fig. 5). 결론: 열평형 근처에서 작업했다.
- **경계 효과** — 각주 [13]: 격자상수 수십 개 안에서만 검출된다. 시야를 결함 없는
  영역으로 골랐다.

## 5. 우리 `A` 스윕이 이 상도에서 어디에 앉는가

`Γ = 5.5683·A` 로 환산:

| `A` | `Γ` | Zahn 상 | 우리가 실제로 본 것 (`notes/simbot/step4/`) |
|---|---|---|---|
| 0.1 | 0.56 | 액체 (`Γ_i` 의 1/100) | `S(q)` 구조 없음 · `\|⟨ψ₆⟩\|`=0.016 · 결함 64.7% |
| 1 | 5.57 | 액체 | `g(r)` 첫봉 1.33 · `\|⟨ψ₆⟩\|`=0.023 · 결함 55.3% |
| **10** | **55.68** | **`Γ_i`=55.87 에서 −0.3%** ← 전이점 | 고리형 `S(q)` · `\|⟨ψ₆⟩\|` 0.102 vs 0.188 (두 시작) · 결함 ~29% |
| 100 | 556.8 | 결정 (`Γ_m` 의 9.3배) | 6겹 점 `S(q)` · `\|⟨ψ₆⟩\|` 0.85~0.97 · 결함 0~2.3% |

### ★ `A=10` 이 hexatic→액체 전이점 위에 있다

우연히 **`Γ_i` 에서 0.3% 안**이다. 이것이 우리가 `A=10` 에서 본 것을 설명한다:

- 두 초기조건의 `|⟨ψ₆⟩|` 가 0.102 vs 0.188 로 **2배** 갈렸다 (§7 #27)
- 자기상관 보정 후 그 차이가 3.4σ 로 내려갔다 (`SD21`)
- `SQ15` 가 "시드 산포 안인가" 를 물었다

**연속 전이점에서 배향 order parameter 가 크게 요동하는 것은 임계 거동이다.**
`SQ15` 의 성격이 "노이즈냐 물리냐" 에서 **"전이점이라서 그렇다"** 로 바뀐다.

> ⚠️ **이것은 아직 우리 관측이 아니라 해석이다.** `Γ_i` 를 우리 계에서 재려면
> `Γ` 미세 스윕과 훨씬 긴 평형화가 필요하다 (저쪽은 며칠). `reproduced: no` 인 이유다.

### `A=100` 은 결정이어야 하고 실제로 결정이다

`Γ=557` 은 `Γ_m` 의 9.3배로 상도에서 한참 깊은 결정 영역이다. 우리 관측(6겹 점 `S(q)`,
`|⟨ψ₆⟩|` 0.85~0.97, 결함 0~2.3%)과 **정성적으로 일치한다.** 전이점에서 멀어 이 비교는
평형화 시간에 둔감하고, 그래서 오늘 검사 가능한 유일한 문헌 대조다.

## 6. 재현하려면 무엇이 필요한가 (`reproduced: no` 를 닫는 조건)

| | 필요한 것 | 지금 |
|---|---|---|
| 1 | `Γ` 를 55~60 구간에서 **1% 해상도**로 스윕 | 우리 격자는 `A` = 0.1/1/10/100 (자릿수 간격) |
| 2 | 평형화를 **완화시간의 여러 자릿수**로 | 10 `τ_d` |
| 3 | `g₆(r)` 의 지수 `η₆` 를 피팅해 `1/4` 교차점 찾기 | `g(r)`·`ψ₆` 스칼라만 있고 `g₆(r)` 곡선이 없다 |
| 4 | Lindemann `γ_L(t)` 의 장시간 극한 | 미구현 |
| 5 | 계 크기 독립성 확인 (`N` 을 3배 이상) | `N`=780 하나 |

`3` 이 가장 값싸다 — `g₆(r) = ⟨exp(i6[θ(r)−θ(r')])⟩` 는 이미 있는 보로노이 `ψ₆ᵢ` 에서
바로 나온다. `1`·`2` 는 비용이고, `2` 는 `SQ13` 이 이미 부딪힌 벽이다.
