## 우리에게 주는 것 (1줄)
프로브 입자의 MSD 하나만으로 매질의 복소점탄성률 `G'(ω), G''(ω)`를 뽑는 관계식 (GSER).
도메인 B 전체가 이 식 위에 서 있다.

## 핵심 식 / 알고리즘 — 우리 무차원 규약으로 변환

### GSER (Laplace 영역)
```
G̃(s) = k_B T / ( π a s ⟨Δr̃²(s)⟩ )
```
`a` = 프로브 **반지름**, `⟨Δr̃²(s)⟩` = **3차원** MSD의 Laplace 변환, `s` = Laplace 변수.

### 실제 구현식 — Mason(2000) 대수적 근사 (Laplace 역변환 회피)
```
α(ω) = d ln⟨Δr²(t)⟩ / d ln t  |_(t = 1/ω)          국소 로그기울기
|G*(ω)| = k_B T / [ π a ⟨Δr²(1/ω)⟩ Γ(1 + α(ω)) ]
G'(ω)  = |G*(ω)| · cos(π α / 2)
G''(ω) = |G*(ω)| · sin(π α / 2)
```
→ 상세·2차보정은 [[mason-2000]]. 여기 식은 1차(가장 널리 쓰이는) 형태.

### 무차원 형태 (master_plan §5 규약)
`σ* = 1, kT* = 1, γ* = 1, τ_B* = 1`, `a* = 1/2`, `G* ≡ G σ³/k_BT`, `ω* ≡ ω τ_B`:
```
|G**(ω*)| = 1 / [ π · (1/2) · ⟨Δr*²(1/ω*)⟩ · Γ(1+α) ]
          = 2 / [ π ⟨Δr*²(1/ω*)⟩ Γ(1+α) ]
```

## 적용 조건 및 한계
- **연속체 가정**: 프로브가 매질의 구조 길이척도보다 훨씬 커야 한다 (`a ≫ ξ_mesh`).
  깨지면 1점/2점 미세유변학이 불일치한다 → [[squires-mason-2010]].
- **국소 균질·등방**: 프로브 주변이 벌크와 같아야 한다. 프로브-매질 흡착/배제층이 있으면 실패.
- **관성 무시**: `ρ a²ω/η ≪ 1`. BD 스케일에서는 항상 만족.
- **비활성 매질**: 활성 요동이 있으면 GSER 자체가 무효 (요동-소산 정리 위반).
- `α(ω)`를 수치미분으로 얻으므로 **MSD가 매끄러워야** 한다. 노이즈가 있으면 로그공간에서
  국소 다항 적합 후 미분해야 한다. → 구현 시 필수 처리.
- 신뢰 대역은 MSD 데이터의 시간 범위 안쪽 **1 decade를 잘라낸** 구간만. 양 끝은 버린다.

## 검증에 쓸 수 있는 수치

**뉴턴 유체 극한** — 이 프로젝트에서 가장 유용한 검증. 자유확산 프로브는
`⟨Δr²⟩ = 6D₀t` (3D), `α = 1`, `Γ(2) = 1` 이므로 GSER은 `G' = 0, G'' = ηω`를 내놓아야 한다.

무차원으로 환산 (`η = γ/(3πσ)` 이므로):
```
G''*(ω*) = ω* / (3π) ≈ 0.106103 · ω*
G'*(ω*)  = 0
```

| 조건 | 예상값 | 우리 무차원 값 | 대조 위치 |
|---|---|---|---|
| 자유확산 프로브, 뉴턴 용매 | `G'=0`, `G''=ηω` | `G''* = ω*/(3π) = 0.1061 ω*`, `G'* = 0` | `tests/` 회귀 + S7 sanity |
| Laplace 왕복 일관성 | — | `MSD → G* → MSD` 상대오차 < 5 % | `simbot/analysis/microrheo.py` |

**유도 검증** (이 항목의 신뢰도 근거): GSER에 `G̃(s) = ηs`를 넣으면
`⟨Δr̃²(s)⟩ = k_BT/(π a η s²)` → 역변환 `⟨Δr²(t)⟩ = k_BT t/(π a η)`.
Stokes–Einstein 3D는 `6D₀t = 6k_BT t/(6πηa) = k_BT t/(πηa)`. **일치.**
→ 위 GSER 형태와 "3D MSD" 규약이 서로 정합함이 확인됨.

## 흔한 함정
1. **`a`는 반지름이다.** 직경을 넣으면 모든 modulus가 정확히 2배 틀린다.
2. **MSD의 차원 규약.** 위 식은 **3성분 합** MSD를 요구한다. 현미경으로 2성분만 측정했다면
   `⟨Δr²⟩_3D = (3/2)⟨Δr²⟩_2D`로 올려야 한다. **미세유변학에서 가장 흔한 오류.**
   → 2D 시뮬레이션의 경우 GSER 자체의 유도가 3D 구형 프로브를 전제하므로,
   2D 결과에 그대로 적용하면 안 된다. 별도 검토 필요.
3. `Γ(1+α)` 보정을 빼먹으면 `α ≈ 0.5` 근방에서 ~10 % 어긋난다.
4. `α > 1` 또는 `α < 0` 이 나오면 (초확산/음의 기울기) 그 주파수는 물리적으로 무효 → 버릴 것.

## 우리 구현과의 차이
- Laplace 변환 대신 Mason(2000) 대수 근사만 구현 예정 (수치 Laplace는 노이즈에 취약).
- `α(ω)`는 로그-로그 공간 국소 2차 적합으로 계산 (단순 유한차분 아님).
