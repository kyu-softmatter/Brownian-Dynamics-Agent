# 콜로이드 사슬 굽힘 강성 — 계수 확정

> **모든 값은 poppler 로 페이지를 렌더링해 이미지에서 직접 읽었다.**
> PDF 텍스트 층은 수학 글리프를 잃는다 (`κ → /.0020`, `π` 소실) — 계수를 텍스트 층에서
> 읽으면 안 된다. 근거: [[env-log]] 3단계

## 1. 읽어낸 원문 (이미지 확인)

```
Eq. (1)   y(x) = -(F_bend/EI) ( L x²/4  -  |x³|/6 )
          κ₀ = 3π a_c⁴ E / 4a³ ,   EI = π E a_c⁴/4     ⇒  κ₀ = 3 EI/a³
          κ = F_bend/δ ,  δ = 중앙 입자의 양 끝 대비 횡변위
          κ(s) = κ₀ (a/s)^(2+d_b) ,  d_b = 1 (직선 사슬)
Langmuir  M_c = F*_bend ( L/2 - |x* - L/2| )                            (3)
          a_c = (3π a² W_SL / 2K)^(1/3)                                 (6)
```

## 2. `Eq. (1)` 의 정체 — 계수 `4`·`6` 이 말하는 것

캔틸레버(길이 `ℓ`, 자유단 하중 `F`)의 처짐은 `y = -(F/EI)(ℓx²/2 - |x|³/6)` 다.
`Eq. (1)` 은 여기에 **`ℓ = L/2`** 를 넣은 것과 정확히 같다.
즉 3점 굽힘의 **절반**을 캔틸레버로 본 식이다 (중앙은 대칭이라 기울기 0 = 고정단).

곡률에서 모멘트가 나온다: `M(x) = EI y'' = -F(L/2 - x)`
→ 지점 `x=L/2` 에서 `M=0` (**단순지지 ✓**), 중앙에서 `M = -FL/2`.

교과서 단순지지·중앙하중 `P` 는 `M_max = PL/4` 이므로 **`F_bend = P/2`** —
`F_bend` 는 총하중이 아니라 **지점 하나의 반력**이다.
PRL 본문("measured directly by the displacement of the **end particles** ... in the
stationary traps")과 Langmuir `Eq. (3)`(모멘트 분포 `M(ξ) = F_bend·ξ`)이 **독립적으로 같은 결론**을 준다.

```
δ = F L³ (1/16 - 1/48) / EI = F L³ / 24EI
κ_PF  ≡ F_bend/δ = 24 EI/L³
κ_sim ≡ P/δ      = 48 EI/L³        ← 우리 BD 가 0.9 % 내로 확인 (C2)
⇒ κ_PF = κ_sim / 2
```

## 3. `Fig. 3` 의 `s/a` 규약 — `a` = 반지름, `s` = 전체 윤곽길이

네 가지 독립 검사가 모두 같은 답:

| 검사 | `κ₀(a/s)³` | `κ₀(2a/s)³` |
|---|---|---|
| Fig 1 의 11-입자 응집체가 `x = -8…8 μm` → `s = 14.7 μm = 20a` | `s/a = 2(N-1)` ✓ | — |
| Fig 3(a) 250 mM 최좌측 사각형 `(s/a ≈ 21, κ ≈ 24 pN/μm)` | **`22.7`** ✓ | `181` ✗ |
| Fig 2(a) 11-입자 @150 mM → `κ ≈ 16.7 pN/μm` | **`18.8`** ✓ | `150` ✗ |
| inset 최좌측점 `κ/κ₀ = 1.0×10⁻³` | `s/a = 10` ✓ (축 눈금과 일치) | `s/a = 20` ✗ |
| 본문 "9 입자 사슬은 트랩 컴플라이언스에 가려진다" | `s/a = 16`, 최좌측 원이 파선(40 pN/μm) 위 ✓ | — |

⇒ **`κ_PF(s) = κ₀ (a/s)³`, `a` = 입자 반지름, `s = (N-1)·2a`, `s/a = 2(N-1)`.**

## 4. ★ 논문 내부에 정확히 `2³ = 8` 배 모순이 있다

| | `κ₀` |
|---|---|
| **(A)** `Eq. (1)` + `Fig. 3` 규약에서 `κ₀ = κ_PF(s=a)` | **`24 EI/a³`** |
| **(B)** 논문이 적은 값 `3π a_c⁴E/4a³` | **`3 EI/a³`** |
| 비 | **`8 = 2³`** |

**기원:** 캔틸레버 관계 `κ = 3EI/ℓ³` 를 쓰면서 `ℓ`(= 반스팬 `L/2`)을 `s`(전체 윤곽길이)와
동일시하면 정확히 `2³` 이 빠진다. `3EI/(L/2)³ = 24EI/L³` 이 (A)와 일치한다.

이것이 **판정이 아니라 산술**임을 강조한다 — (A)는 논문 자신의 `Eq. (1)` 과
`Fig. 3` 자료 붕괴에서 나오고, `48EI/L³` 는 우리 BD 가 `p = -2.998 ± 0.003`,
계수 `0.991` 로 독립 확인했다 ([[colloidal-chain--bending-rigidity]] C1·C2).

**어느 쪽을 쓰나:** `Fig. 3` 의 **적합된 `κ₀`** 를 쓴다 — 자료에 직접 붙어 있다.
JKR 경로(`a_c` → `EI` → `3EI/a³`)는 (B) 규약이라 그대로 쓰면 8배 틀린다.

## 5. 확정된 환산 — 우리 시뮬레이션의 `k_θ`

`EI = k_θ · b`, `b = σ = 2a` (이산 사슬), `κ₀ = 24 EI/a³` 에서:

| `[MgCl₂]` | `κ₀` (Fig 3b/본문) | `EI` | `k_θ` |
|---|---|---|---|
| 10 mM | `64 ± 0.5 mN/m` | `1.059×10⁻²¹ N·m²` | `7.203×10⁻¹⁶ J` |
| 250 mM | `≈ 0.21 N/m` | `3.474×10⁻²¹` | `2.364×10⁻¹⁵` |
| 500 mM | `≈ 0.64 N/m` | `1.059×10⁻²⁰` | `7.203×10⁻¹⁵` |

`a = 0.735 μm`, `σ = 1.47 μm`. 계산: `scripts/furst_coefficient.py`

### 이전에 보고한 `11.77` 배의 분해
```
11.77 = 2.00  (48 = P/δ  vs  24 = F_bend/δ — 반력 규약)
      × 5.887 (EI from a_c=40 nm  vs  EI from 적합 κ₀ with 계수 24)
```
둘 다 이제 설명된다. `a_c ≈ 40 nm` 는 저염 근사값이고, 본문의 JKR 예측 `80 mN/m` 는
(B) 규약 값이다.

## 6. 상호작용의 실체 — 왜 `U_ij(r_ij)` 로 못 쓰나

| 방향 | 무엇 | 쌍포텐셜로 표현 가능? |
|---|---|---|
| **법선** | DLVO. PMMA 표면전위 `≈ -40 mV` 의 이중층 반발을 `MgCl₂` `50–500 mM` 로 **차폐** → vdW 1차 최소로 비가역 응집 → **JKR 접착 접촉**, 접촉반경 `a_c ≈ 40–46 nm` | ✅ 가능 |
| **접선** | 유한 접촉면의 **접촉역학**. `W_SL`(고-액 접착에너지)로 **접촉선이 핀** 되어 회전·구름에 저항 | ❌ **불가능** |

- `a_c = (3πa²W_SL/2K)^(1/3)`, `K = 2E/3(1-ν²)`, `W_SL⁰ = γ_L(1+cos θ₀)` (Young–Dupré)
- `κ₀ ∝ a_c⁴ ∝ W_SL^(4/3)` → **결합 강성은 접착에너지가 정한다.** Langmuir 논문이
  계면활성제로 `W_SL` 를 낮춰 `κ₀` 와 `M_c` 가 같이 내려가는 것을 보여 이를 확인했다.
- `M_c` 초과 = **접촉선 de-pinning** → `32 ± 15 nm ≈ a_c` 만큼 미끄러짐.

⇒ 이 상호작용은 **접촉면이라는 내부 자유도**를 가진다. 중심간 거리의 함수가 아니다.
`bond.Harmonic` 이 법선(접촉 유지)을, **`angle.Harmonic` 이 접선(접촉면의 탄성)** 을 맡는다.
`M_c` 의 슬립은 우리 모델에 **대응물이 없다** — 각 스프링은 항복하지 않는다. 유효범위 경계다.
