## 2. 뼈대 (Ch 2) ★★★ — 응력은 두 조각이고, 기억은 한 조각에만 있다

### 2.1 두 단계로 쪼갠다 ([L] p.27)

> ① 주어진 배치(configuration)에 대해 응력을 계산하는 공식을 만든다.
> ② 그 배치가 시간에 따라 어떻게 변하는지의 이론을 만든다.

**①은 모든 복합유체에서 구조가 같고, ②가 유체를 구분합니다.** 어려운 쪽은 ②입니다.
우리 프로젝트는 지금까지 ②만 해왔습니다(BD 가 배치를 진화시킴). ①을 안 해서
"측정한 K′ 이 무엇의 계수인가" 가 매번 흔들렸습니다.

### 2.2 응력의 두 성분

| | **유체역학 성분** `T^(p)_H` | **열역학 성분** `T^(p)_Th` |
|---|---|---|
| 어디서 오나 | 입자가 있어서 생기는 흐름 교란 | 배치를 비평형에 붙잡아 두는 데 드는 일 |
| 계산 조건 | 입자가 **힘·토크 자유**, 복원기구 **없음** | 정지한 유체에서 **복원력만** 으로 움직일 때의 흐름 |
| 흐름을 끊으면 | ⭐️ **즉시 0** | 유한 시간에 이완 |

⭐️⭐️ **이것이 이 책에서 우리에게 가장 중요한 명제입니다** ([L] p.33, p.35, p.180 에서 세 번 반복):

> creeping flow 가정 때문에 교란 속도·응력은 순간 속도기울기의 **선형 함수**다. 따라서
> 흐름을 멈추면 유체역학 성분은 **그 순간 정확히 0** 이 된다.
> ⟹ **점탄성(기억·탄성)은 전부 열역학 성분에서 온다.**

그리고 열역학 성분이 0 이 아니려면 **셋이 다 필요합니다**:

1. 선호되는 평형 배치가 있다 (자유에너지 최소)
2. 그 평형으로 되돌리는 **복원기구** 가 있다 — **그리고 그것이 부과된 변형 모드에 저항해야 한다**
3. 이완시간 τ_c 가 변형 시간척도 안에 있다: `τ_c·|E| = O(1)` ([L] p.39)

“복합유체와 소분자 액체의 차이는 이완 시간척도가 변형 과정의 시간척도 **안에 있는가**
뿐이다” ([L] p.36). 물이 뉴턴인 이유는 τ_c 가 없어서가 아니라 너무 짧아서입니다.

### 2.3 강도의 순서 ([L] p.38) — 어느 성분이 지배하나

| 계 | 유체역학 : 열역학 |
|---|---|
| 강체 Brownian 입자 현탁액 | **대략 반반** |
| 고분자 용액 / 아핀 변형하는 방울·유연 사슬 | **열역학이 지배** (고분자 문헌은 유체역학 성분을 아예 무시) |
| 점도가 일치하는 비혼합 방울 | 유체역학 성분이 **정확히 0** (아핀 변형) |
| 혼화성 방울(계면장력 0) | 열역학 성분이 **0**, 유체역학만 |

### 2.4 상호작용력이 있으면: 힘 모멘트 항 (2.27) ⭐️

희박이 아니면 `T^(p)_Th` 에 항이 하나 더 붙습니다 ([L] p.37, 식 (2.27) 마지막 항):

```
T^(p)_Th  ⊃  (1/V) Σ_α  F_i^(α) x_j^(α)
```

즉 **입자에 걸린 상호작용력과 위치의 곱의 합** — 우리가 아는 **virial/force-dipole** 형태입니다.
책의 직관적 설명: *"입자 쌍은 각 입자에 걸린 힘 × 입자 간 거리 에 비례하는 알짜 힘 이중극자를
만든다"* ([L] p.47). `F^(α)` 는 **콜로이드 상호작용력 `F_P` 이거나 유효 Brownian 힘 `F_Br`** 입니다.

그리고 Brownian 운동은 **유효 힘으로 정확히 치환됩니다** ((2.59), [L] p.47):

```
F_Br^(α) = −kT ∇_α ln P_N(x_1,…,x_N)      (Σ_α F_Br^(α) = 0)
```

이것이 **BD 코드에서 응력을 실제로 계산할 수 있다** 는 근거입니다 (§3.4).

### 2.5 Einstein 의 “열역학 힘” 논증 (2.37)–(2.48)

일반화된 형태로 외워둘 것 (검증 ✅ `[DERIV]`):

| | 병진 | 회전 |
|---|---|---|
| 유효 힘/토크 | `F_Br = −kT d(ln n)/dh` (2.43) | `L_Br = −kT p∧(∂ln ψ/∂p)` (2.44) |
| 확산계수 | **`D = kT·M`** (2.42), 구는 `M = 1/(6πμa)` | **`D_r = kT·ϖ`** (2.48), ϖ = 회전 이동도 |
| 텐서 형태 | **`D = kT M`** (각주 11) — 이동도 텐서가 이방이면 확산도 그렇다 | 축대칭 타원체는 W∥L 이라 스칼라 |

⭐️ `D = kT M` 이 **`abp-rod` 의 "BD 로는 이방성 병진 마찰 불가"** 결론의 이론적 배경입니다:
확산 이방성은 **이동도 텐서** 에서 오고, 이동도 텐서의 비대각·이방 성분은 유체역학(HI)이 만듭니다.
BD 는 M 을 스스로 만들지 않고 **우리가 넣어준 것을 쓸 뿐** 입니다.

### 2.6 이 틀이 부과하는 가정 — 규칙 7′ 용 목록

이 책의 결과를 우리 결과와 대조할 때 **"이론이 추가하는 가정"** 은 정확히 이 목록입니다
([L] pp.28–34 에서 명시적으로 열거):

1. 입자 스케일 **Re → 0** (creeping flow). 정량: `ρ|∇u|d²/μ ≪ 1` (각주 4)
2. **중성 부력** (침강 없음), 외부 알짜 힘·토크 없음 — 외부 토크는 **반대칭 응력** 을 만듭니다 (2.18)
3. 매질이 **뉴턴 유체**
4. **스케일 분리**: 평균화 부피가 입자를 통계적으로 많이 담으면서도 그 안에서 부과 흐름이 위치 무관
5. **국소 균질**: 각 입자가 보는 흐름은 선형 `u = Ω·x + E·x` (2.22)
6. 미시 관성 없음 → 두 문제(부과 흐름 / 복원기구)가 **선형중첩 가능**. 유한 변형이면 깨집니다 ([L] p.38)

> 우리 BD 가 **부과하는** 가정과 비교: BD 는 1·6 을 자동으로 만족(관성 없음, 과감쇠)하고 3 을
> 가정하며, **HI 를 아예 뺀** 상태입니다. [L] p.46: *"HI 가 없으면 `R = 0` 이고 입자는 그냥
> 부과된 흐름과 함께 병진한다."* 4·5 는 우리가 스스로 검사해야 하고, **`chain-bend` 는 4 를
> 원천적으로 만족할 수 없습니다** (사슬이 하나뿐이라 평균화할 것이 없음 → §3.2).

★ 실무 결론: 진짜 `G′(ω)` 를 원하면 **주기경계 + 사슬 망 + 외부 트랩 없이 전단 변형을 부과**

### 3.3 `abp-rod` 는 이 책의 틀 밖에 있다 (그리고 그게 흠이 아니다)

[L] 의 열역학 성분은 **"평형 상태로 되돌리는" 기구** 로 정의됩니다 ([L] p.36). 활성 입자는
평형 상태가 없고 활성힘은 비보존력입니다. 또 (2.18)–(2.19) 는 외부 토크가 없다고 가정합니다.
⟹ ABP 의 응력(문헌의 swim stress)은 이 책에 없습니다.

우리가 `abp-rod` 에서 `pe_per_particle` 대신 `⟨cos Δθ⟩` 를 쓴 것은 **이 사실의 실무적 반영**
이었습니다 (가리킬 퍼텐셜 에너지가 없음). 이제 그 선택에 이론적 이름이 붙습니다.

Kramers 형태 ((11.15b), [L] p.494) ⭐️ **검증 ✅ `[DERIV]`**:

```
T^(p) = n ⟨F_s R⟩ − n kT I
```

- `F_s` = 연결자 장력(스프링 힘), `R` = 말단간 벡터, `n` = 수밀도.
- **평형에서 정확히 0** 이어야 합니다 — 부호·전인자 규약의 골든 테스트입니다.
  Hookean 이면 `⟨RR⟩_eq = (kT/ϖ₀)I` 이므로 `T^(p) = n(ϖ₀⟨RR⟩ − kT I) = 0`. 실행 확인: `max|T| = 0` (기계정밀도).
- Giesekus 형태 (11.15c): `T^(p) = (nζ/4)·▽⟨RR⟩` (▽ = 상위대류 미분). ⚠︎미검증(중간 유도 미확인).

⭐️ **`−nkT I` 항을 빼먹으면 평형에서 0 이 안 되고, 그걸 "잔류 탄성" 으로 오독합니다.**
우리 프로젝트에 이미 있는 함정 계열입니다("퍼텐셜을 에너지로만 검증하면 힘을 검증한 것이 아니다").

일반 다체 계는 (2.27) 의 힘 모멘트 항 + Brownian 유효 힘 (2.59)를 씁니다. **BD 구현 시 주의**:
`F_Br = −kT∇ln P_N` 은 우리가 이미 넣는 랜덤힘의 **앙상블 평균 효과** 이므로,
랜덤힘의 순간값을 virial 에 그대로 더하면 **이중계산** 입니다. ⚠︎미검증 — 실제로 계산하기 전에
`kT=0` 결정론 런과 대조해서 확인해야 합니다(우리 프로젝트의 기존 교훈과 같은 방법).

## 4. 규약 — 틀리면 **조용히** 2배·6배 틀리는 것들

### 4.1 ⭐️ Pe/Wi 의 분자는 `|E|` 이고, `|∇u|` 가 아니다 ([L] p.106)

> E 와 Ω 는 둘 다 `O(|∇u|)` 지만 **효과가 전혀 다르다. 와도(vorticity)는 입자를 균일하게
> 회전시킬 뿐 무작위 평형 상태에 아무 영향이 없다.** 배향을 정하는 것은 변형률 성분이다.

```
Pe = Wi = |E| / D_r          ([L] p.106)
```

세 가지가 여기 걸려 있습니다 (전부 실행 검증 ✅ `[DERIV]`):

1. **√2 함정**: `|E| ≡ √(2 E:E)`. 단순전단에서 이 규약이면 `|E| = γ̇` 로 [L] (1.32) `Wi = γ̇/D_r`
   와 일치합니다. `√(E:E)` 를 쓰면 **√2 = 1.414 배** 어긋납니다. (규약 출처: [L] p.75 의
   `Ê = E/(2E:E)^{1/2} = E/γ̇`)
2. **순수 회전류에서 Pe = 0**: `|∇u|` 로 재면 0 이 아닌데 배향은 평형 그대로입니다.
3. **준구(near-sphere) 보정**: `r−1 ≪ 1` 이면 옳은 척도는 `|E|(r−1)/D_r` 입니다 ([L] p.107) —
   변형률의 배향 효과가 와도에 비해 약해집니다. 종횡비 1 근처에서 Pe 를 그냥 `|E|/D_r` 로 쓰면
   **과대평가** 합니다.

### 4.2 ⭐️ 배향 이완시간은 `1/(6 D_r)` 이다 — `1/D_r` 도 `1/(2D_r)` 도 아니다

[L] (5.121b) 의 손실항이 `De/(36 + De²)` (De = ω/D_r) 이므로 극이 **De = 6** 입니다.
실행 검증 ✅ `[DERIV]`: 최댓값 위치 `De = 6.00000`, 그리고 이 함수는 `λ = 1/(6D_r)` 의
**단일 Maxwell 모드와 비례상수 하나로 정확히 동일** (최대 편차 < 1e-12).

⟹ **희박 축대칭 입자 현탁액의 선형점탄성은 정확히 단일 Maxwell 모드입니다.**

⚠️ 이것은 **3D 의 l=2(응력에 관여하는) 모드** 입니다. 1차 모멘트 `⟨p⟩` 나 2D 계의 각도상관은
다른 계수를 갖습니다 — `abp-rod` 의 `⟨cos Δθ⟩` 에 6 을 갖다 붙이면 **틀립니다**. ⚠︎미검증
(2D 계수는 이 책에서 확인하지 않았습니다).

### 4.3 SAOS 에서 법선응력차는 **2ω** 로 진동한다 ([L] p.183)

> 흥미로운 특징 하나는 법선응력차가 **전단응력과 부과 흐름의 두 배 진동수로** 진동한다는 것이다.

⟹ **락인 검출을 ω 에서만 하면 법선응력을 원리적으로 못 봅니다.** 우리 `lockin.k_star` 는
ω 에서 뽑으므로 전단(교차) 성분만 봅니다. 법선응력을 원하면 2ω 채널이 따로 필요합니다.

관련 규약 ([L] (5.120), (5.122)): `T₁₂ = η′γ̇₀cos ωt + η″γ̇₀sin ωt = G′γ₀ sin ωt + G″γ₀ cos ωt`,
그리고 **`η′ = G″/ω`, `η″ = G′/ω`** (엇갈립니다 — 순서를 뒤집는 것이 흔한 실수).

### 4.4 Jeffery 회전 ((2.34), [L] p.42)

```
ṗ = Ω·p + G[E·p − p(p·E·p)],      G = (r²−1)/(r²+1)
```

검증 ✅ `[DERIV]`: `G(1) = 0` (구는 변형률에 반응 안 함) · `G(r→∞) → 1` · r 에 단조증가.
**모양 의존성은 전부 G 하나에 들어갑니다** (Bretherton 1962) — 축대칭이면 타원체가 아니어도
이 형태가 성립하고 G 만 다릅니다.

## 6. 이 책이 우리에게 열어주는 새 케이스 후보

### 6.1 ⭐️ 준희박 막대의 `D_r` 억제 — **BD 가 옳은 도구인 드문 경우**

[L] p.223 (Shaqfeh & Fredrickson 1990; Dhont & Briels 2003):

> 매우 길고 가는 입자의 극한에서는 **입자 간 유체역학 상호작용이 흐름에 의한 회전 운동을
> 수정하는 데 중요하지 않다** (Jeffery 해가 그대로 성립).

한편 `D_r` 의 **1/(nL³)² 억제는 배제부피(입체) 효과** 이지 HI 가 아닙니다 — 관(tube) 은
이웃 입자가 만드는 **기하적** 구속입니다.

⟹ **HI 없는 BD 로 이 물리를 정직하게 잡을 수 있습니다.** 그리고 예측이 자유 파라미터
하나(β)만 갖는 정량 예측이라 **규칙 7′ 의 `hypothesis` 역할** 로 등록할 수 있습니다.
우리 `abp-rod` 는 예측 5종이 전부 `implementation_check` 여서 발견이 0 이었는데,
이 케이스는 **처음으로 진짜 `hypothesis` 를 갖는 막대 케이스** 가 됩니다.

⚠️ 비용 주의: `nL³ ≈ 30`, 3D, 막대 다수 → 우리 환경(단일코어, MPI 없음)에서 큰 계입니다.
`bench_chain_bend` 처럼 **먼저 스텝률을 재세요**.

### 6.2 하드스피어 쌍분포의 흐름 왜곡 — 부호가 예측되어 있다 ([L] p.75, Batchelor 1977)

```
g(r) = g_eq(r)[1 + Pe·g⁽¹⁾(r) + …],   g⁽¹⁾ = −(e_r·Ê·e_r) f(r),  f > 0 단조감소
```

⟹ **압축 사분면에서 쌍확률이 높고, 신장 사분면에서 낮다.** 2D BD 로 바로 측정 가능한
부호 예측이고, 우리에게 없는 종류의 검증입니다(공간 상관의 흐름 왜곡).
그리고 `N₁` 은 **전부 직접 Brownian 성분에서 온다** ([L] p.76) — 이것도 켜고/끄고로 시험 가능.

⚠️ Pe → ∞ (비 Brownian) 단순전단에서는 **닫힌 궤도 때문에 `g` 가 미정** 입니다 ([L] p.76) —
특이 극한이므로 "Pe 를 키워 극한을 보자" 가 안 됩니다.

### 6.3 사슬 **망** → 진짜 `G′(ω)`

§3.2 의 조건(주기경계·트랩 없음·전단 부과·Kramers 응력)을 만족하는 케이스.
`chain-bend-2d-oscill` 의 `observation.yaml` F1 이 예고한 것이 정확히 이것이고,
[L] Ch 2 + Ch 11 이 **필요한 공식 전부** 를 줍니다.

## 7. 함정 목록 (이 책을 쓰다가 틀릴 수 있는 것)

1. **`|E|` 대 `|∇u|`** — √2 또는 무한대 배 (순수 회전류) 오차. §4.1
2. **`η′ = G″/ω`, `η″ = G′/ω`** 를 뒤집기. §4.3
3. **`1/(6D_r)` 을 다른 모드·다른 차원에 적용** — 6 은 3D l=2 계수. §4.2
4. **Kramers 응력에서 `−nkT I` 누락** → 평형에서 0 이 안 되고 가짜 탄성. §3.4
5. **Brownian 유효 힘의 이중계산** — `F_Br = −kT∇ln P_N` 은 랜덤힘의 평균 효과. §3.4
6. **Oldroyd-B 를 일반 고분자 유체로 사용** — 유도상 **희박 선형사슬 전용** 이고 전단담화를
   못 냅니다 ([L] p.496). 전단담화가 보이면 모델이 아니라 계가 다른 것입니다.
7. **폐쇄근사(closure)는 응력에 필요한 것만 닫으면 된다** — 응력은 `⟨pp⟩`·`⟨pppp⟩`(=α, β) 두
   모멘트만 필요하고 완전한 `ψ(p)` 는 그보다 훨씬 많은 정보를 담습니다 ([L] p.108, Advani–Tucker 1987).
   ★ **Bingham 폐쇄**(Chaubal & Leal 1998, [L] §6.6.2)는 `ψ` 가 Bingham 분포라고 가정하는
   fitted closure 인데, **그 분포가 항상 물리적으로 허용되므로 병리적 결과를 절대 내지 않습니다** —
   폐쇄근사를 고를 때 "정확도" 말고 **"실패 모드가 있는가"** 를 봐야 한다는 사례입니다. ⚠︎미검증
8. **"유효 회전확산 ∝ γ̇" 모형**(Folgar–Tucker 계열)은 **흐름이 없으면 이완이 없습니다**
   ([L] p.219) → 정지 상태의 탄성을 예측하지 못합니다. 평형 이완이 필요한 관측량에 쓰면 안 됩니다.
9. **준구에서 Pe 보정 누락** (§4.1-3).
10. **`nL³ = O(1)` 을 하드 경계로 쓰기** — 실험은 10–50. 우리 검사에 넣을 때 **경고(⚠)** 여야 하고
   하드 실패(❌)면 안 됩니다.
