### D2 는 우연이 아니라 필수다

카드 §3 · [[box-shape-confounds-initial-condition-comparison]] — 상자 모양이 바뀌면
`r_cut`(`= min(L)/2` 파생) 과 허용 `k` 격자가 함께 바뀌어 `S(k)` 6겹 변조가 **28배**
갈렸다. 정사각으로 고정하면 그 교란이 사라진다. 그래서 **`init = random` 만 돌린다** —
`hex` 초기배치는 정사각 상자에서 주기경계가 격자를 끊어 인공 결함을 만든다
(`build_soft2d` 가 예외를 던진다).

### D3 — 커버리지가 정하는 것, 정하지 않는 것 ★★

`σ` 는 **동역학에 들어가지 않는다.** 경질 코어가 없고 `n* = 1` 이 정의상 성립하므로
**무차원 물리는 `A` 하나로 완전히 결정된다.** `σ` 가 정하는 것은 둘뿐이다:

1. **시간 척도** — `τ_d = d²/D₀`, `D₀ = kT/(3πησ)`. `σ` 없이는 초를 붙일 수 없다.
2. **점입자 이상화의 타당성** — 5 µm 원판 100개가 얼마나 붐비는가.

⇒ **커버리지를 바꿔도 `ψ₆`·`g(r)`·결함은 한 자리도 바뀌지 않는다.** 바뀌는 것은 축
라벨과 `τ_d` 의 초 값이다. 감도 `|S| = 0` 이므로 CLAUDE.md §질문 규칙에 따라 묻지 않고
정했다.

| 값 | 근거 | 신뢰도 |
|---|---|---|
| `σ = 5.0 µm` | 사용자 지시 | high |
| **`d/σ = 3`** → `d = 15.0 µm` | `φ < 10 %` 는 `d/σ > 2.8025` 를 요구한다. `3` 은 그 위의 가장 깔끔한 값 (`simbot.build.box_si_for_coverage`) | high |
| **`L = 150.0 µm`** | `L = √N · d`, `N = 100` | high (derived) |
| **`φ = 8.7266 %`** | `φ = (π/4)(σ/d)² = π/36` | high (derived) |
| `T = 298.15 K` · `η = 0.890 mPa·s` | `knowledge/wiki/concepts/water-298k.md`, IAPWS 298.15 K | high |
| **`τ_d = 2292.4 s = 38.21 분`** | `d²/D₀`, `D₀ = 0.09815 µm²/s` (`simbot.units.scales_soft2d`) | high (derived) |

**바꿀 위치** — `scripts/soft2d_time_series.py` 의 `SIGMA_SI` · `D_OVER_SIGMA`.

### ⚠️ D3 의 부작용 — `A = 0.1` 에서 기준 원판이 겹친다

선행 40런(`runs/2026-07-29_soft-r3-2d-A-sweep`)의 실측 최소분리를 `σ` 로 환산하면:

| `A` | 최소분리 | `σ` 단위 | 겹침? | 겹침을 없애려면 |
|---|---|---|---|---|
| **0.1** | `0.2172 d` | **`0.652 σ`** | **겹친다** | `φ < 3.71 %` |
| 1 | `0.4586 d` | `1.376 σ` | 없음 | `φ < 16.5 %` |
| 10 | `0.7164 d` | `2.149 σ` | 없음 | `φ < 40.3 %` |

`A/r³` 에 경질 코어가 없으므로 **모델은 이 겹침을 허용한다** — 그림에 충실하다.
다만 `A = 0.1` 에서는 "5 µm 원판" 이라는 그림이 물리적으로 성립하지 않는다:
`βU(0.652 σ) = 0.1/0.652³ = 0.36 kT` 로 열요동이 쉽게 넘는 장벽이다.
⇒ **`A = 0.1` 의 결과는 점입자 소프트 반발계의 결과로만 읽어야 한다.**
이것을 S2 에 반증 가능한 형태로 봉인한다 (P6).

### D4 — 시간분해가 요구하는 것

선행 40런은 **평형화 구간을 버리고** 프로덕션 후반 절반만 분석했다. 그러면
"무엇이 되었는가" 에는 답하지만 **"언제 되었는가" 에는 답하지 않는다.**

⇒ 이 런은 `equil_tau = 0` 으로 두고 **`t = 0` 부터 전 구간을 표집한다.**
총 `80 τ_d` (선행과 같은 총량) · `400` 프레임 (`stride = 0.2 τ_d`).
`60–80 τ_d` 창이 선행 런의 "프로덕션 후반 절반" 과 대응하므로 **직접 교차검증이 된다.**

## 3. 게이트 — 카드 §7 을 그대로

| 게이트 | 켬/끔 | 이 런에서 |
|---|---|---|
| `force_displacement` (`max\|F\|Δt ≤ 0.005`) | ✅ **지배** | `A` 마다 초기배치에서 **실측**해서 `dt` 를 정한다 |
| `thermal_displacement` (`√(2Δt) ≤ 0.03`) | ✅ | 기준 길이는 `d` |
| `r_cut + buffer ≤ L/2` | ✅ | `L* = 10` → `r_cut = 4.80`, buffer `0.1` |
| `min_separation > r_min` | ✅ | `r_min = 0.1` |
| `packing_fraction` | ❌ 끔 | 경질 코어가 없어 정의되지 않는다 (기준 원판 커버리지는 **게이트가 아니라 기록**) |
| 평형화 판정 | ⚠️ **보고만** | 임계값이 없으므로 표류를 재고 판정은 제안만 |
| 초기조건 독립성 | ❌ 이 런에서 끔 | D2 때문에 `random` 만. 선행 런이 `A ≤ 10` 에서 `0.8σ` 이내 일치를 이미 보였다 |

## 4. 남은 모호성

- `A = 10` 은 Zahn 전이점 `Γ = 59.88` 의 `−0.3 %` 다 (`Γ = 55.68`). **레짐 경계**이므로
  시간분해에서 가장 느릴 것으로 예상한다 — P3 의 내용이다.
- `N = 100` 은 `A = 10` 의 `r_cut` 요구(`N ≥ 252`)를 만족하지 않는다 (카드 §9).
  `βU(r_cut) = 0.09 kT`. **`N` 수렴 검사는 이 런의 범위가 아니다** — 미결로 남긴다.
