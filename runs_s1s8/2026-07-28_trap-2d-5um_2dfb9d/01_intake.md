## 3. 모호성 — 임의 해석하지 않고 후보를 나열한다

### A1. 차원 — 2D인가, 3D 입자에 xy 트랩인가
| | 해석 | 결과 차이 |
|---|---|---|
| **A1-a** ✅ 채택 | **2D.** 입자가 평면에서만 움직인다 | `⟨r²⟩ = 828 nm²`, MSD plateau `1657 nm²` |
| A1-b | 3D 입자, `xy`만 구속, `z` 자유 | **`MSD_z`가 무한 증가** — plateau 없음 |
| A1-c | 3D 등방 트랩 (`r` 정의가 축약 표기) | `⟨r²⟩ = 1243 nm²`, plateau `2485 nm²` |

> **판별자:** `⟨r²⟩` 비가 **정확히 `3/2`** (A1-c/A1-a). `z` 방향 MSD가 포화하는가.
> 성분별 `⟨x²⟩ = 414 nm²`는 **세 해석에서 모두 동일** → 차원을 구별하지 못한다.
> 반경 통계 또는 `z` 거동을 봐야 한다.

### A2. `a`와 `R`의 관계
| | 해석 | 결과 차이 |
|---|---|---|
| **A2-a** ✅ 채택 | `R = 5 μm`이 **입자 반지름**, `a`는 입자 라벨 | `γ = 8.06e-8 kg/s`, `τ_trap = 8.06 ms` |
| A2-b | `a`가 반지름 기호(값 미지), `R`은 다른 길이(트랩 유효반경 등) | `τ_trap ∝ a` 로 비례 변화 |

> **판별자:** `τ_trap = γ/k = 6πηa/k` 는 `a`에 **선형 비례**한다.
> 그런데 **`⟨x²⟩ = kT/k`는 `a`와 `η`에 완전히 무관하다.**
> ⇒ **정적 측정(`⟨x²⟩`)은 `k`와 `T`만 검증하고, 동적 측정(`τ_trap`)은 `a`와 `η`를 검증한다.**
> 두 측정이 직교하므로 A2는 동적 측정으로만 판별된다. (감도 분석 S7b의 근거)

## 7. ★ 계 × 목적동역학 카드 — 없어서 만들었다

`knowledge/wiki/systems/_index.md`의 매트릭스에 **조화 트랩 행이 없었다.**
규약상 카드 없이 진행하면 즉흥 무차원화가 되므로 카드를 먼저 만들었다:
→ [`passive-sphere--harmonic-trap.md`](../../knowledge/wiki/systems/passive-sphere--harmonic-trap.md)

**이 계가 카드 체계의 논지를 가장 세게 증명한다:**

```
tau_D    = sigma^2/D0 = 1947 s   (32.5 분)
tau_trap = gamma/k    = 8.06 ms
비       = 2.41e5
```

> 보편 규약(`τ_D` 기준)에 `dt* = 5e-5`를 적용하면
> **`dt = 5e-5 × 1947 s = 97 ms = 12 × τ_trap`.**
> 발산하지 않는다 — 그래서 더 위험하다. **완화 과정을 통째로 건너뛰고도 그럴듯한 숫자가 나온다.**
