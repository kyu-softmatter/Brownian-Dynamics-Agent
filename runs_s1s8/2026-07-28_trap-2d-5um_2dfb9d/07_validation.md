## 2. INCONCLUSIVE 2건 — 예견된 것이다

`P8`·`P9` 는 **예측 문서를 쓸 때 이미 판별력이 부족할 것이라고 기록되어 있었다**
(`knowledge/wiki/findings/hoomd-brownian-scheme-and-noise.md` §1: *"판별하려면 표본을 36배 늘려야"*).

| | 값 |
|---|---|
| EM 편향 (`dt*=5e-3`) | `0.251 %` |
| 측정 통계오차 (시드 4개) | `±0.446 %` |
| **판별력 = 편향/SE** | **`0.56σ`** |
| 3σ 판별에 필요한 표본 배수 | **`(3/0.56)² = 29×`** |

> **이것은 실패가 아니라 설계의 한계다.** `dt* = 5e-3` 은 프로덕션용으로 골랐고
> (편향을 통계오차 아래로 밀어넣는 것이 목적), 그 목적을 정확히 달성했다.
> **적분기 검증은 일부러 큰 `dt*` 에서 해야 한다** — `dt*=2e-2` 에서는 판별력이 `3.8σ` 였고
> 그때 EM 이 확정됐다 (`tests/test_s5_scheme.py::test_B1`).

**INCONCLUSIVE 를 PASS 로 바꾸는 비용**: 시드 4 → 116개. T2 티어에서 약 2.5분.
현재 결론이 그에 의존하지 않으므로 **하지 않는다.**

## 3. 자기일관성 검사 — 예측에 없던 강한 확인

MSD plateau 와 직접 측정한 분산은 **독립 경로**다 (전자는 시계열, 후자는 스냅샷).
`plateau = 2d ⟨x*²⟩` 여야 한다:

| dim | plateau | `2d ⟨x*²⟩` | 비 |
|---|---|---|---|
| 2 | `4.0215` | `4.02308` | **`0.99961`** |
| 3 | `6.0171` | `6.01656` | **`1.00009`** |

**두 경로가 0.04 % 이내로 일치한다.** 분석 코드의 오류를 배제하는 가장 강한 증거다.

| dim | `dt*` | `τ_fit/τ_trap` |

`τ_trap = γ/k = 6πηa/k` 이므로 이것이 **`η`·`a` 를 검증하는 유일한 창**이다
(`⟨x²⟩` 는 `η`·`a` 에 무관 — 01_intake §3 A2 판별 구조).

## 5. 위치 분포 — 예측하지 못했던 것을 예측하게 됐다

봉인된 `P7` 은 "Gaussian" 만 요구했다. 그런데 HOOMD 노이즈가 균일분포이므로
**정상분포는 정확히 Gaussian이 아니다.** AR(1) 정상 초과첨도:

```
g_x = g_u (1-a^2)/(1+a^2) ~ g_u * dt*,   a = 1-dt*,   g_u(균일) = -1.2
   =>  kurtosis = 3 - 1.2 dt*
```

| dim | `dt*` | 첨도 측정 | 해석 예측 | 편차 |
|---|---|---|---|---|
| 2 | `5e-3` | `2.9968` | `2.9940` | `0.23σ` |
| 2 | `2.5e-3` | `2.9790` | `2.9970` | `1.47σ` |
| 3 | `5e-3` | `2.9979` | `2.9940` | `0.39σ` |
| 3 | `2.5e-3` | `2.9904` | `2.9970` | `0.66σ` |

> **정확히 `3.000` 이 나오면 오히려 이상하다.** 이 편차는 알려진 오차이고,
> 그것을 재현하는 것이 무작정 Gaussian 을 확인하는 것보다 강한 검증이다.
> 구현: `simbot.analysis.trap.em_uniform_noise_excess_kurtosis`

## 6. ★ 분석 과정에서 발견한 오류 — 첫 KS 검정은 무효였다

| | |
|---|---|
| **증상** | KS p값이 4개 조건 전부 `0.0000` — `P7` FAIL 로 보였다 |
| **원인** | `분류: analysis`. 마지막 20 프레임을 표본으로 썼는데 프레임 간격이 16 스텝 = `0.08 τ_trap` 이라 **20프레임 전체가 `1.6 τ_trap` 안**에 있었다. 서로 상관된 50,000 점을 iid 로 취급 → KS 귀무분포가 틀림 → **거짓 기각** |
| **처방** | `2 τ_trap` 이상 떨어진 프레임만 사용 (`decorrelation_tau=2.0`). 추가로 표본을 측정 표준편차로 규격화 — 폭 차이(EM 편향)는 `P1` 의 일이고 `P7` 은 **형태**만 봐야 한다 |
| **결과** | `p = 0.0000 → 0.29 – 0.53` |
| **재발 방지** | `check_position_distribution` 이 `dt_star` 와 `frame_interval_steps` 를 **필수 인자로 요구**한다. 독립성을 계산하지 않고는 호출할 수 없다 |

> **교훈: 상관된 표본에 KS 를 걸면 항상 기각한다.** `n` 이 커질수록 더 확실히 기각하므로
> "표본이 많아서 신뢰할 수 있다"는 직관이 정확히 반대로 작동한다.
> `master_plan` §11.7 의 실패모드 목록에 추가할 것.

## 8. 모호성 판정

### A1 (차원) — **시뮬레이션이 답할 수 없다**
2D 와 3D 를 **둘 다** 돌렸고 둘 다 각자의 해석해와 일치했다. 어느 쪽이 사용자의 계인지는
**그림이나 실험 데이터만 답할 수 있다.** 시뮬레이션이 제공하는 것은 판별 기준이다:

| | 2D | 3D |
|---|---|---|
| `⟨r²⟩` | **`833 nm²`** (rms 28.9 nm) | **`1246 nm²`** (rms 35.3 nm) |
| MSD plateau | **`1666 nm²`** | **`2492 nm²`** |
| `⟨x²⟩` 성분별 | `417 nm²` | `415 nm²` ← **구별 불가** |

> **성분별 `⟨x²⟩` 로는 차원을 알 수 없다.** 반경 통계나 `z` 거동을 봐야 한다.

### A2 (`a` vs `R`) — 열려 있음
`τ_trap` 측정이 `8.05 ms` 이고 `a = 5 μm` 가정과 일치하지만, 이는 **가정을 넣어 계산한 값과
시뮬레이션이 일치한다**는 뜻일 뿐 실험과 대조한 것이 아니다. **실험 `τ_trap` 이 필요하다.**
