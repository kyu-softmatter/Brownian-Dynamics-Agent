## A1 (공간 차원) — **닫힘. 2D 확정.**

| | |
|---|---|
| **출처** | 사용자 직접 확인, 2026-07-28: *"계는 2디 평면이었어."* |
| **채택된 후보** | `A1-a` — 2D. 입자가 평면에서만 움직인다 |
| **기각된 후보** | `A1-b` (3D 입자 + xy 구속), `A1-c` (3D 등방 트랩) |
| **S1 당시 신뢰도** | `medium` (근거: 식 `r = √(x²+y²)` 에 `z` 없음) |
| **결과** | ✅ **S1 의 추론이 맞았다** |

### 이 해소가 바꾸는 것

**결론의 확정값이 2D 분기로 고정된다:**

| 양 | 확정값 (2D) | 기각된 3D 값 |
|---|---|---|
| `⟨x²⟩` 성분별 | **`416.58 ± 1.85 nm²`** (rms **20.41 nm**) | 415.34 (구별 불가) |
| `⟨r²⟩` | **`833.17 nm²`** (rms **28.87 nm**) | ~~1246.01~~ |
| MSD plateau | **`1665.68 nm²`** | ~~2492.27~~ |
| `τ_trap` | **`8.0567 ± 0.0300 ms`** | 8.0381 (차원 무관) |
| `f_c` | **`19.7 Hz`** | 동일 |

**3D 런 8개는 버리지 않는다 — 대조군(control)이 된다.**
같은 코드가 서로 다른 차원에서 각자의 해석해(`plateau = 2d`, `⟨r²⟩ = d·kT/k`)를
재현했다는 것은 **구현이 차원을 올바르게 처리한다는 독립 증거**다.
차원을 하나만 돌렸다면 얻을 수 없었던 검증이다.

### 사전 판별자가 옳았는지 확인
`01_intake.md` §3 이 예고한 판별자: *"`⟨r²⟩` 비가 정확히 `3/2`"*
측정: `1246.01 / 833.17 = 1.4955` — 예측 `1.5` 와 **0.3 % 일치.** ✅
판별자 자체가 작동함이 확인되었다.

또한 예고대로 **성분별 `⟨x²⟩` 는 차원을 구별하지 못했다** (417 vs 415 nm², 통계오차 내).
차원을 묻는 문제에 이 양을 쓰면 안 된다는 사전 경고가 옳았다.

## A2 (`a` 와 `R` 의 관계) — **닫힘. 간결성으로 채택 (데이터 아님).**

| | |
|---|---|
| **확인 결과** | 사용자 2026-07-28: 실험 `f_c` 측정값 **없음** |
| **채택** | `A2-a` — `R = 5 μm` 이 입자 반지름 |
| **근거의 종류** | ⚠️ **간결성(parsimony). 측정이 아니다.** |

### 왜 데이터 없이도 닫는가

`A2-b`(= `a` 가 반지름 기호이고 값은 미지, `R` 은 다른 길이)를 채택하면
**그림 어디에도 입자 크기가 없다.** 그런데 그림은 `k_t`·`T`·퍼텐셜 형태를 모두 명시했다.
크기만 빠뜨린 그림은 **문제로서 불완전하다** — `γ` 를 계산할 수 없어 어떤 동역학도 못 푼다.

`A2-a` 는 그림을 완전하게 만든다. 그리고 `R` 의 지시선이 원을 직접 가리키므로
읽기 자체도 자연스럽다. `a` 는 입자 라벨이거나 반지름 기호를 `R` 로 정의한 것 둘 중 하나이고,
**두 해석 모두 `A2-a` 와 정합한다.**

> **열어둔 채 방치하지 않는 이유:** 미결 항목은 시간이 지나면 "왜 미결이었는지"가
> 사라진다. 근거의 **종류**(측정 vs 간결성)를 명시해 닫는 것이 더 정직하다.

### ★ A2 가 결론에 미치는 영향 — 절반은 전혀 없다

`⟨x²⟩ = k_BT/k` 는 `a`·`η` 에 **해석적으로 무관**하다. 따라서:

| 결과 | `a` 의존성 | A2 가 틀렸다면 |
|---|---|---|
| **`⟨x²⟩ = 416.58 ± 1.85 nm²`** | **없음** | **변하지 않는다** ✅ |
| **`⟨r²⟩ = 833.17 nm²`** | **없음** | **변하지 않는다** ✅ |
| **MSD plateau `= 1665.7 nm²`** | **없음** | **변하지 않는다** ✅ |
| 위치분포 (Gaussian, rms 20.41 nm) | 없음 | 변하지 않는다 ✅ |
| `τ_trap = 8.0567 ms` | **`∝ a`** | `τ_trap = 8.057 ms × (a/5 μm) × (η/η_water)` |
| `f_c = 19.7 Hz` | **`∝ 1/a`** | `f_c = 19.7 Hz × (5 μm/a) × (η_water/η)` |
| `D₀ = 0.0514 μm²/s` | `∝ 1/a` | 동일 비례 |

**정적 결과(평형 통계)는 A2 와 완전히 독립이고, 동적 결과만 선형 재척도된다.**
따라서 동적 결과는 위 **매개변수 형태로 보고한다** — 가정을 숨기지 않는 방식이다.

### 반증 조건 (falsification test)
```
f_c = k/(2 pi gamma) = k/(12 pi^2 eta a)
```
| 관측 | 결론 |
|---|---|
| 실험 `f_c ≈ 19.7 Hz` | `A2-a` + 물 가정 **둘 다** 지지 |
| 실험 `f_c ≠ 19.7 Hz` | `a ≠ 5 μm` **또는** `η ≠ η_water`. **둘을 구별할 수 없다** — `f_c` 는 `ηa` 곱만 정한다 |
| `f_c` 가 2배 | `ηa` 가 절반 |

> `f_c` 하나로는 `a` 와 `η` 를 분리할 수 없다. 분리하려면 **입자 크기 독립 측정**
> (현미경 이미지)이나 **다른 크기 입자로 반복**이 필요하다.
