## 1. 질문에 대한 답

> **질문 (S1):** 이 광집게에 갇힌 반지름 5 μm 입자의 열요동을 정량화하고 해석해와 대조하라.

> ✅ **차원 확정: 2D 평면** — 사용자 확인 2026-07-28 ([`09_ambiguity_resolution.md`](09_ambiguity_resolution.md)).
> S1 의 추론(`r = √(x²+y²)` 에 `z` 없음 → 2D, 신뢰도 `medium`)이 **옳았다.**

**답:** 정량화했고, 해석해와 일치한다.

| 양 | 확정값 (2D) | 가정 의존성 |
|---|---|---|
| 성분별 등분배 `⟨x²⟩` | **`416.58 ± 1.85 nm²`**  (rms **`20.41 nm`**) | **없음** — `k`·`T` 만으로 결정 |
| 반경 `⟨r²⟩` | **`833.17 nm²`**  (rms **`28.87 nm`**) | **없음** |
| MSD plateau | **`1665.68 nm²`** | **없음** |
| 완화시간 `τ_trap` | **`8.0567 ± 0.0300 ms`** `× (a/5 μm) × (η/η_water)` | `a`·`η` 에 선형 |
| 코너주파수 `f_c` | **`19.7 Hz`** `× (5 μm/a) × (η_water/η)` | `a`·`η` 에 반비례 |

> **정적 결과는 가정과 완전히 독립이고, 동적 결과만 선형 재척도된다.**
> `⟨x²⟩ = k_BT/k` 는 `a`·`η` 에 해석적으로 무관하므로, 매질을 물로 가정한 것과
> `R` 을 반지름으로 읽은 것(A2)이 등분배 결과를 오염시키지 않는다.
> 동적 결과는 **가정을 숨기지 않도록 매개변수 형태로 적었다.**

MSD 는 `4(k_BT/k)(1−e^{−t/τ})` 형태를 `R² = 0.99998` 로 따르고,
위치 분포는 Gaussian 이다 (`KS p = 0.29–0.53`).

**입자는 지름 10 μm 인데 20 nm 만 움직인다** — 자기 크기의 0.2 %.

봉인된 정량 예측 **9개 중 7개 PASS, 2개 INCONCLUSIVE, 0개 FAIL.**

### 3D 런 8개는 대조군이 되었다
차원이 2D 로 확정되었으므로 3D 분기는 답이 아니지만 **버리지 않는다.**
같은 코드가 두 차원에서 각자의 해석해(`plateau = 2d`, `⟨r²⟩ = d·kT/k`)를 재현했고,
사전 판별자 `⟨r²⟩(3D)/⟨r²⟩(2D) = 3/2` 가 측정 `1.4955` 로 **0.3 % 이내** 확인되었다.
차원 하나만 돌렸다면 얻을 수 없었던 독립 검증이다.

## 2. 근거 3줄
1. **`τ_trap/τ_예측 = 0.9990 ± 0.0037`** (4개 조건 전부 `1σ` 이내, 최고 정밀도 0.08 %).
2. **독립 경로 2개가 0.04 % 로 일치** — MSD plateau(시계열)와 직접 분산(스냅샷)의 비가 `0.99961`.
3. **알려진 수치 오차를 재현했다** — 위치 분포 첨도가 `2.997`, 해석 예측 `3 − 1.2 dt* = 2.994` 와 `0.23σ`.

## 3. ★ 부수 검증 — 이 계는 방법론을 시험했고, 방법론이 틀렸다면 알 수 없었다

> **부수 질문 (S1 §6-⑤):** 이 계에서 `τ_D` 기준 무차원화가 실제로 실패하는가?

**실패한다.** 측정으로 확인된 시간척도 분리:

```
tau_D    = sigma^2/D0 = 1947 s = 32.5 분
tau_trap = gamma/k    = 8.06 ms                 (측정 8.057 ± 0.030 ms)
비       = 2.41 x 10^5
```

보편 규약(`τ_D` 기준, `dt* = 5e-5`)을 적용하면 **`dt = 97 ms = 12 × τ_trap`** 이 된다.
발산하지 않는다 — **완화 과정을 통째로 건너뛰고도 그럴듯한 숫자가 나온다.**

⇒ **`(계 × 목적동역학)` 카드 체계가 실측으로 정당화되었다.** BD_agent 가 경고한
"트랩 계에서 `Δt` 가 완화시간의 54배" 가 여기서 **24만 배** 규모로 재현되었다.

### ★ 추가된 한계 — 항력 모델 (2026-07-28 사후 검토)

`a = 5 μm` 는 광집게로 **큰 입자**여서 세 보정이 모두 커진다.
전문: [`concepts/stokes-drag-corrections.md`](../../knowledge/wiki/concepts/stokes-drag-corrections.md)

| 보정 | 크기 | 우리 모델이 재현하나 |
|---|---|---|
| **비정상 항력 (Basset)** `a/δ` @ `f_c` | **`4.25 %`** (통계오차의 7배) | ❌ **불가** — Markovian BD 의 원리적 한계. GLE 필요 |
| **벽 근접 (Faxén)** `h = 10 μm` | `γ` **`2.29배`** → `τ_trap = 18.4 ms` | ⚠️ `γ(h)` 로 교체하면 가능 (미구현) |
| **중력** `ℓ_trap/ℓ_g` | **`1.35`** · 처짐 `27.5 nm > ℓ_trap` | ✅ 2D **수평**면이면 면내 무관 (확정된 2D 가 이 문제를 비껴갔다) |

> **정직한 서술:** `τ_trap = 8.057 ± 0.030 ms` 는 **무한매질 · 정상 · 중력 무시** Stokes
> 항력에 대한 값이다. 실제 광집게 실험은 벽 위치에 따라 **8–18 ms**, `f_c` 근처에서
> **4 % 비정상 보정**을 받는다.
>
> **시뮬레이션은 자기 자신에 대해 정확하다** (`τ_fit/τ = 0.9998 ± 0.0008`).
> 부정확한 것은 **모델과 실제 물의 대응**이고, 그 크기가 우리 통계 정밀도보다 크다.
> ⇒ 실험 대조 시 `0.6 %` 정밀도를 주장할 수 없다. **주장 가능한 상한은 `~5 %`** 다.
