**① `ψ₆` 의 `N` 의존성.** 파선은 액체 기울기 (`p = 0.5`, `|⟨ψ₆⟩| ~ N^-1/2`), 점선은 KTHNY hexatic-액체 경계 (`p = 0.0625`, `η₆ = 1/4`) 이며 각 `A` 의 첫 점에 고정했다. **절대값이 아니라 기울기가 상을 판별한다** — 유한계에서는 무질서한 계도 `1/√N` 규모의 `ψ₆` 를 낸다. `A=0.1`: `p = 0.508` ± `0.020` → `η₆ = 2.03`, 판독 **liquid-like** · `A=1`: `p = 0.464` ± `0.013` → `η₆ = 1.86`, 판독 **liquid-like** · `A=10`: `p = 0.316` ± `0.037` → `η₆ = 1.27`, 판독 **between**. **② 결함 분율은 국소량이므로 `N` 에 평탄해야 한다** — 기울어지면 `N=100` 에 유한크기 효과가 있었다는 뜻이다. ⚠ 두 점으로는 멱함수 **형태**를 검증할 수 없다; 지수만 뽑았다.
